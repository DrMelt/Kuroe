# 流程示例

## 单线撰写

制定大纲后引用容器「成稿」写出全文，再引用库节点「校对全文」校对，定稿写入 `out/单线定稿.md`。

示例覆盖节点库定义、容器模型槽位声明、容器引用、库节点引用与文件写入节点。

```json
{
  "Nodes": [
    {
      "Name": "撰写正文",
      "Kind": "Llm",
      "Prompt": "按大纲撰写正文。",
      "Tools": ["file"],
      "Inputs": [{ "Name": "大纲", "Description": "待撰写的章节大纲。" }],
      "Outputs": [{ "Name": "正文", "Type": "Text", "Description": "按大纲写好的章节正文。" }]
    },
    {
      "Name": "合成全文",
      "Kind": "Llm",
      "Prompt": "把正文合成一篇完整文档。",
      "Inputs": [{ "Name": "正文", "Description": "章节正文。" }],
      "Outputs": [{ "Name": "全文", "Type": "Text" }]
    },
    {
      "Name": "校对全文",
      "Kind": "Llm",
      "Prompt": "校对全文，交回修正后的定稿。",
      "Inputs": [{ "Name": "全文", "Description": "待校对的全文。" }],
      "Outputs": [{ "Name": "定稿", "Type": "Text" }]
    },
    {
      "Name": "成稿",
      "Kind": "Container",
      "Models": ["章节作者", "统稿者"],
      "Inputs": [{ "Name": "大纲", "Description": "待撰写的章节大纲。" }],
      "Outputs": [{ "Name": "全文", "Ref": "合成@全文", "Description": "容器内写好的全文。" }],
      "Nodes": [
        { "Label": "撰写", "Use": "撰写正文", "Model": "章节作者", "From": [{ "大纲": "@大纲" }] },
        { "Label": "合成", "Use": "合成全文", "Model": "统稿者", "From": [{ "正文": "撰写@正文" }] }
      ]
    }
  ],
  "Flows": [
    {
      "Name": "单线撰写",
      "Description": "制定大纲后经容器写出全文，再引用库节点校对，定稿写入文件",
      "Models": [
        { "Name": "规划者", "Model": "<模型>" },
        { "Name": "章节作者", "Model": "<模型>" },
        { "Name": "统稿者", "Model": "<模型>" },
        { "Name": "校对者", "Model": "<模型>" }
      ],
      "Start": {
        "Outputs": [
          { "Name": "目标", "Type": "Text", "Description": "要写的文档主题。" },
          { "Name": "风格", "Type": "Text", "Description": "写作风格要求。" }
        ]
      },
      "Nodes": [
        {
          "Name": "整体",
          "Kind": "Container",
          "Nodes": [
            {
              "Name": "制定大纲",
              "Kind": "Llm",
              "Model": "规划者",
              "Prompt": "写出可撰写的章节大纲。",
              "Inputs": [
                { "Name": "目标", "Description": "任务目标。" },
                { "Name": "风格", "Description": "写作风格要求。" }
              ],
              "Outputs": [{ "Name": "大纲", "Type": "Text" }],
              "From": [{ "目标": "Start@目标", "风格": "Start@风格" }]
            },
            {
              "Label": "成稿",
              "Use": "成稿",
              "Models": { "章节作者": "章节作者", "统稿者": "统稿者" },
              "In": { "大纲": "制定大纲@大纲" }
            },
            {
              "Label": "校对",
              "Use": "校对全文",
              "Model": "校对者",
              "From": [{ "全文": "成稿@全文" }]
            },
            {
              "Name": "保存定稿",
              "Kind": "FileWrite",
              "Path": "out/单线定稿.md",
              "Inputs": [{ "Name": "正文" }],
              "From": [{ "正文": "校对@定稿" }]
            }
          ]
        }
      ]
    }
  ]
}
```

## 双版比选

同一容器「成稿」引用两次，各绑一套模型写出两版全文，再由执行节点比选，选定的定稿写入 `out/比选定稿.md`。

示例覆盖容器多次引用、`In` 端口映射与多来源向同一执行节点接线。

    {
      "Name": "撰写正文",
      "Kind": "Llm",
      "Prompt": "按大纲撰写正文。",

      "Inputs": [{ "Name": "大纲", "Description": "待撰写的章节大纲。" }],

    },
    {
      "Name": "合成全文",
      "Kind": "Llm",
      "Prompt": "把正文合成一篇完整文档。",
      "Inputs": [{ "Name": "正文", "Description": "章节正文。" }],
      "Outputs": [{ "Name": "全文", "Type": "Text" }]
    },
    {
      "Name": "成稿",
      "Kind": "Container",
      "Models": ["章节作者", "统稿者"],
      "Inputs": [{ "Name": "大纲", "Description": "待撰写的章节大纲。" }],

    {
      "Name": "双版比选",

      "Models": [
        { "Name": "规划者", "Model": "<模型>" },
        { "Name": "作者甲", "Model": "<模型>" },
        { "Name": "主编甲", "Model": "<模型>" },
        { "Name": "作者乙", "Model": "<模型>" },

                { "Name": "风格", "Description": "写作风格要求。" }
              ],
              "Outputs": [{ "Name": "大纲", "Type": "Text" }],
              "From": [{ "目标": "Start@目标", "风格": "Start@风格" }]
            },
            {
              "Label": "甲稿",
              "Use": "成稿",
              "Models": { "章节作者": "作者甲", "统稿者": "主编甲" },
              "In": { "大纲": "制定大纲@大纲" }
            },
            {
              "Label": "乙稿",
              "Use": "成稿",

              "In": { "大纲": "制定大纲@大纲" }
            },
            {
              "Name": "比选",
              "Kind": "Llm",

              "Prompt": "比选两版全文，交回选定的一版。",
              "Inputs": [{ "Name": "甲稿" }, { "Name": "乙稿" }],
              "Outputs": [{ "Name": "定稿", "Type": "Text" }],
              "From": [{ "甲稿": "甲稿@全文", "乙稿": "乙稿@全文" }]
            },
            {
