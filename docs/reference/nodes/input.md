# 输入

`Kind: Input` 不启动执行。节点启动后停在待输入，不等待输入齐备，也不消费来源取值。回答写入唯一的 `Text` 输出端口。

## 类型参数

| 参数       | 类型   | 含义                     |
| ---------- | ------ | ------------------------ |
| `Question` | string | 等待时的提示文本，可省略 |

## 端口

- `Inputs` 可取 `Text` 或 `Signal`，但输入端口不构成启动条件。
- `Outputs` 至多声明一个 `Text` 端口，不能使用触发。
- `From` 可以写，来源与取值不参与等待与产出。

## 行为

节点启动后自行停在待输入，输入端口不作为启动条件。回答非空时按回答发布一次，空回答不写入输出。节点取消后不再接收，任务恢复时仍在等待的节点重新声明接收。

## 示例

```json
{
  "Name": "补充目标",
  "Kind": "Input",
  "Parameters": { "Question": "补充这次任务的目标。" },
  "Outputs": [{ "Name": "回答", "Type": "Text" }]
}
```

Console 的回答入口见[操作指南](../../console/操作指南.md#任务概览)，CLI 不支持输入节点，见[命令行接口](../../cli/命令行接口.md#流程支持范围)。
