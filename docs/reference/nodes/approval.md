# 审批

`Kind: Approval` 不启动执行。输入齐备后停在待批准，批准后把停驻时的输入内容按同名输出端口放出。

## 类型参数

| 参数       | 类型   | 含义                     |
| ---------- | ------ | ------------------------ |
| `Question` | string | 等待时的提示文本，可省略 |

## 端口

- `Inputs` 必须至少声明一个端口，可取 `Text`、`Context` 与 `Signal`，其中 `Context` 至多一个。
- 对外端口由 `Inputs` 派生，不单独声明 `Outputs`。
- 批准本身不带内容，输出取停驻时的内容，输出端口不携带触发值。
- 派生输出端口一律是 `Plain` 模式，不声明触发模式，审批输出不能作为 `From` 的触发来源。

## 行为

输入齐备后节点停在待批准。批准后发布一次，下游按新版本重新评估。节点不接受 `MaxExecutions`，取消后不再接收，任务恢复时仍在等待的节点重新声明接收。

## 示例

```json
{
  "Name": "批准发布",
  "Kind": "Approval",
  "Question": "确认发布这一版草稿。",
  "Inputs": [
    { "Name": "草稿", "Type": "Text", "Role": "Content" },
    { "Name": "完成", "Type": "Signal" }
  ],
  "From": [{ "草稿": "撰写@正文", "完成": "撰写@完成" }]
}
```

Console 的批准入口见[操作指南](../../console/操作指南.md#任务概览)。
