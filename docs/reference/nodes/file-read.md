# 文件读取

`Kind: FileRead` 启动执行。`From` 任一组齐备且来源有新产出时按路径变量解析 `Path` 并读取文件，内容写入唯一的 `Text` 输出端口。读取在独立执行中运行，不占用任务状态锁。

## 类型参数

| 参数        | 类型   | 含义                                                           |
| ----------- | ------ | -------------------------------------------------------------- |
| `Path`      | string | 文件路径，必填，可含 `{变量}` 占位符                           |
| `Variables` | object | 路径变量名到 `Text` 输入端口的映射，与 `Path` 的占位符一一对应 |
| `MaxChars`  | int    | 单次读取的字符上限，未写时 8000，0 不限制，负数在导入时报错    |

## 端口

- `Inputs` 至少声明一个 `Signal` 端口作为触发。
- `Text` 输入全部是路径变量端口，不能声明承载内容的其他 `Text` 输入。
- `Outputs` 必须恰好声明一个 `Text` 端口，读取内容写入该端口。

## 读取

路径变量由静态输入或上游取值给出，`root` 是相对路径的基准。解析结果必须落在工作区根内，越界、空值或占位符缺失时停在阻塞。

目标是目录或文件不存在时停在阻塞。文本按 UTF-8 解码并识别 BOM，超过 `MaxChars` 时截断并附截断标记。

## 示例

```json
{
  "Name": "读取说明",
  "Kind": "FileRead",
  "Path": "{root}/说明.md",
  "Variables": { "root": "任务路径" },
  "MaxChars": 12000,
  "Inputs": [
    { "Name": "任务路径", "Type": "Text", "Mode": "Constant" },
    { "Name": "触发", "Type": "Signal" }
  ],
  "Bindings": { "任务路径": "@任务路径" },
  "From": [{ "触发": "计划@结论" }],
  "Outputs": [{ "Name": "说明", "Type": "Text" }]
}
```

路径变量与工具变量的完整规则见[工具变量](../流程定义.md#工具变量)，任务目录见[安装与运行](../../usage/安装与运行.md#任务目录)。
