# 容器

`Kind: Container` 组合成员并限定作用域，自身不执行，对外只暴露 `Outputs` 声明的端口。

## 字段

| 字段       | 含义                                                |
| ---------- | --------------------------------------------------- |
| `Nodes`    | 有序子节点，至少一个                                |
| `Inputs`   | 传入端口，静态输入写 `Mode: Constant`               |
| `Bindings` | 静态传入端口到父作用域来源的绑定                    |
| `From`     | 动态传入端口到父作用域来源的连接，只有一组          |
| `Outputs`  | 对外端口，`Ref` 写 `成员@端口` 或 `@本节点静态输入` |

容器的外部接线与执行节点一致：动态输入写在 `From`，静态输入写在 `Bindings`。`Bindings` 只写引用文本，不写 `Condition`。内联容器连接自身声明的 `Inputs`，引用容器连接库定义声明的 `Inputs`。值写 `来源@端口` 或 `@更外层端口`，容器自身的接线在父作用域求值，来源必须在容器外部。根容器的 `From` 与 `Bindings` 可以取 `Start@端口`。容器静态输入必须由 `Bindings` 绑定，容器输入不支持 `Default`。

容器只写一组 `From`，组内覆盖全部动态输入。成员经 `@端口` 读取的传入来源必须唯一，多组会让同一个 `@端口` 对应多个来源。`From` 的触发连接可以写 `Condition: Negative`，来源端口必须是触发端口；条件只门控本次发布，不改变成员读取到的内容。

容器成员只能引用本容器子树内的节点与容器传入端口，容器外的节点与端口不可见。容器不可声明 `Question`、`Emission` 与类型参数。`MaxExecutions` 是容器自身发布次数上限，不传给成员，未写时没有上限。

容器输出与其他节点使用同一形状。`Ref` 来源可以是本节点静态输入或子树内成员的输出端口，常量性与类型必须一致；动态输出转发成员产出，常量输出由 `Value` 或成员常量提供。容器发布是快照，版本、触发位与动态输出内容在发布时确定，成员后续变化在下一次发布时生效。`Mode: Trigger` 的输出按来源触发值门控下游，来源没有触发值时按 true。触发输入只门控容器发布，来源为 false 时抑制本次发布，触发输入自身的新版本不驱动发布。

## 示例

```json
{
  "Name": "成稿",
  "Kind": "Container",
  "Inputs": [
    { "Name": "大纲", "Type": "Text", "Mode": "Constant", "Role": "Content" },
    { "Name": "MODEL_NAME", "Type": "Text", "Mode": "Constant" }
  ],
  "Outputs": [{ "Name": "全文", "Type": "Text", "Mode": "Constant", "Ref": "撰写@正文" }],
  "Nodes": [
    { "Label": "撰写", "Use": "撰写正文", "Bindings": { "大纲": "@大纲", "MODEL_NAME": "@MODEL_NAME" } }
  ]
}
```
