# 内置工具

内置工具按工具路径分组，路径段用 `/` 分隔。模型看到的函数名是路径中的 `/` 换成 `_`，如 `file/read/ReadFile` 对应 `file_read_ReadFile`。

| 路径           | 页面                       | 内容                                   |
| -------------- | -------------------------- | -------------------------------------- |
| 契约工具       | [契约工具](contract.md)    | 执行节点自动附加的交回、状态与上报工具 |
| `file`         | [文件](file.md)            | 读取、列出、取信息与写入、替换、移动   |
| `git`          | [git](git.md)              | 状态、差异、历史与暂存、提交、分支操作 |
| `dotnet`       | [dotnet](dotnet.md)        | 环境查询、包查询与构建、测试、发布     |
| `KuroeInfo`    | [KuroeInfo](kuroe-info.md) | 任务、执行、流程、目录与配置查询       |
| `source`       | [导出资料](source.md)      | 随产物导出的源码与文档查询             |
| `GetLocalTime` | [时间](time.md)            | 当前时区与当地时间                     |

契约工具由引擎自动附加，见[契约工具](contract.md)。路径参数在调用前校验，路径基准由 `root` 变量给出，节点用 `ToolPorts` 映射，见[工具变量](../流程定义.md#工具变量)。

命令模板工具写在 `.kuroe/tools.json`，不属于内置工具，见[工具配置](../工具配置.md#命令模板工具)。Console 内置助手的固定白名单见[内置助手](../../console/内置助手.md)。
