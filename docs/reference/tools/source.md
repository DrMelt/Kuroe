# 导出资料

`source` 工具组只读随产物导出的源码与文档，只由 Kuroe.Console 提供，Kuroe.Cli 不读取。导出目录是产物目录下的 `source/`，保留仓库相对路径，生成物与 `.docs` 参考资料不入内。

## 函数

| 函数                         | 参数                                                                                     | 作用                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `source/ListSourceDirectory` | `path` 可选                                                                              | 列出导出目录内一个目录的直接子项，缺省列出导出目录根 |
| `source/ReadSourceFile`      | `path` 必填，`from`、`to`、`maxChars`、`maxLineChars` 可选，`lineNumbers` 开关，缺省为真 | 读取导出目录内文件指定行号范围，缺省读到文件尾       |

## 行为

给出的路径相对导出目录解析，必须落在导出目录内，越界、空字符串与空白都拒绝；`ListSourceDirectory` 的 `path` 省略时列出导出目录根。`ReadSourceFile` 的行号从 1 起，`to` 省略或超出文件行数时读到文件尾。

`lineNumbers`、`maxChars` 与 `maxLineChars` 的含义与读取输出格式与文件工具的 `ReadFile` 一致，见[文件](file.md#文本)。文本按 UTF-8 解码。

导出目录的来源与产物形态见[安装与运行](../../usage/安装与运行.md#工作目录)与[从源码构建](../../usage/从源码构建.md#发布)。
