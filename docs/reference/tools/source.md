# 导出资料

`source` 工具组只读随产物导出的源码与文档，只由 Kuroe.Console 提供，Kuroe.Cli 不读取。导出目录是产物目录下的 `source/`，保留仓库相对路径，生成物与 `.docs` 参考资料不入内。

## 函数

| 函数                         | 参数                                                                                     | 作用                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `source/ListSourceDirectory` | `path` 可选                                                                              | 列出导出目录内一个目录的直接子项，缺省列出导出目录根 |
| `source/ReadSourceFile`      | `path` 必填，`from`、`to`、`maxChars`、`maxLineChars` 可选，`lineNumbers` 开关，缺省为真 | 读取导出目录内文件指定行号范围，缺省读到文件尾       |

## 行为

给出的路径相对导出目录解析，必须落在导出目录内，越界、空字符串与空白都拒绝；`ListSourceDirectory` 的 `path` 省略时列出导出目录根。`ReadSourceFile` 的行号从 1 起，`to` 省略或超出文件行数时读到文件尾。

`lineNumbers` 缺省为真，读取输出的每行是 `{行号} |{内容}` 后接该行在文件中的原始终止符，未被单行上限截断时 CRLF、CR、LF 按行保留，所选范围的末行也写出其终止符；文件末行本身没有终止符时不写；以终止符结尾的文件在终止符之后还有一个空行，该空行没有终止符。`lineNumbers` 为假时只输出每行的 `{内容}` 与原始终止符，不输出行号与 ` |` 分隔符。`maxChars` 是正文总字符上限，缺省 10000，允许 1 到 50000，超出 50000 拒绝；正文含行号、保留的行内容、保留的终止符与单行截断标注，不含范围标记与正文前提示。`maxLineChars` 是单行行长上限，缺省 300，只要求大于 0。行长含行内容与终止符，CRLF 计 2 个字符，CR 与 LF 各计 1 个字符，文件末行没有终止符计 0。行长超过上限时保留行内容前缀，丢弃余下内容与终止符，在内容后标注 `（本行共 N 字符，已截断）`，N 为原始行长，截断不切开代理对。截断行不输出终止符，下一行直接接在标注之后。输出文本整体以 `<<<KUROE_TEXT_BEGIN>>>` 开头，以 `<<<KUROE_TEXT_END>>>` 结尾，结束标记后不追加换行；文本以终止符结尾时结束标记位于下一行，否则与末行正文同行。文件没有内容时只返回提示，不带范围标记。工具生成的总截断提示、文件尾提示与行号范围提示使用 LF，并位于开始标记之前；行内截断标注位于行内容之后。行号与请求范围一致并按末行位数右对齐。起始行超出文件长度时拒绝并提示。到达文件尾时正文前给出实际返回的行号范围，正文超过 `maxChars` 字符时截断并在正文前提示，截断不切开 CRLF 与代理对，截断时不报文件尾。目录列表超过 200 条时截断。文本按 UTF-8 解码。

导出目录的来源与产物形态见[安装与运行](../../usage/安装与运行.md#产物目录)与[从源码构建](../../usage/从源码构建.md#发布)。
