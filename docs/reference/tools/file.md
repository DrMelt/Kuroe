# 文件

文件工具分 `file/read` 与 `file/write` 两组，白名单写 `file` 放行两组，写 `file/read` 只放行读取。

## 函数

| 函数                      | 参数                                                                                          | 作用                                                               |
| ------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `file/read/ReadFile`      | `path` 必填，`from`、`to`、`maxChars`、`maxLineChars` 可选，`lineNumbers` 开关，缺省为真      | 读取文本文件指定行号范围，缺省读前 50 行，超出文件尾时读到文件尾   |
| `file/read/SearchText`    | `pattern` 必填，`paths`、`extensions`、`ignoreCase`、`unique` 可选                            | 在路径范围内按字面文本搜索，按文件分组返回带行号的匹配行           |
| `file/read/ListDirectory` | `path` 可选                                                                                   | 列出目录直接子项，缺省为路径基准目录                               |
| `file/read/GetFileInfo`   | `path` 必填                                                                                   | 取文件的字节大小、创建、修改、访问时间与只读、隐藏、系统、归档属性 |
| `file/write/WriteFile`    | `path`、`content` 必填，`encoding` 可选                                                       | 覆盖写入文本，文件不存在时创建，父目录缺失时自动创建               |
| `file/write/ReplaceText`  | `paths`、`pattern`、`replacement` 必填，`extensions`、`ignoreCase`、`dryRun`、`encoding` 可选 | 在多个文本文件中按字面文本批量替换                                 |
| `file/write/MoveFile`     | `source`、`target` 必填                                                                       | 移动文件或目录，同目录改名为重命名，目标已存在时拒绝               |
| `file/write/DeleteFile`   | `path` 必填，`recursive` 开关                                                                 | 删除文件或目录，目录缺省只删除空目录，路径基准目录本身拒绝删除     |

`MoveFile` 的目标落在源目录之内时拒绝，目标父目录缺失时自动创建。`DeleteFile` 的 `recursive` 开关为真时连同目录内容一起删除。

## 路径

路径相对 `root` 变量给出的路径基准。给出的路径参数在调用前校验，必须落在工作区根内，越界、空字符串或空白都拒绝；可省略的路径参数省略时取路径基准。校验按字符串进行，不解析符号链接与目录联接点。路径校验不是执行期隔离，见[安全与权限](../../usage/安全与权限.md)。

全部路径参数拒绝工作区根下的 `.kuroe` 与 `.git`。

## 搜索

`SearchText` 在 `paths` 给出的目录或文件内搜索。`paths` 省略或为空数组时搜索路径基准目录，写成单个字符串时按一个路径处理；目录递归展开，文件按单个文件处理，多个范围重叠时按完整路径去重。`extensions` 省略或为空数组时不限制后缀，条目可写 `cs` 或 `.cs`，比较忽略大小写，空条目与含 `*`、`?`、路径分隔符的条目拒绝。范围与后缀取交集。

匹配按字面文本进行，不解释正则。`ignoreCase` 为真时忽略大小写，缺省区分大小写。按整行匹配，同一行命中多处只展示一行。摘要中的匹配处数按 `pattern` 的非重叠出现次数计。输出每行保留包含命中位置的 1000 字符窗口，行内容长度超过 1000 字符时在内容后标注包含终止符的完整行长与展示的行内容区间，行长统计 CRLF 为 2 个字符、CR 与 LF 各 1 个字符、文件末行没有终止符计 0。结果按相对路径序数排序，文件内按行号升序，每个文件一段，匹配行使用 `行号 |内容` 格式，行号按该文件匹配行中的最大行号右对齐。

`unique` 为真时要求 `pattern` 在范围内恰好出现 1 次，出现次数按非重叠匹配计，同一行多处按多次计。出现 0 次或多次时调用失败；出现多次时列出已定位的匹配行。扫描在第二次出现后停止，判定不受输出截断影响。

输出上限 8000 字符，超过时截断并在正文前写截断提示，提示与读取一致。无匹配时报告扫描的文件数。递归跳过路径准入规则命中的目录，即工作区根下的 `.kuroe` 与 `.git`，跳过重解析点目录、无法读取的文件与目录以及二进制文件。构建产物与导出资料不单独排除，用 `paths` 与 `extensions` 收窄范围。

## 批量替换

`ReplaceText` 在 `paths` 给出的目录或文件内批量替换。`paths` 必填，用于限定替换范围，写成单个字符串时按一个路径处理；目录递归展开，文件按单个文件处理，多个范围重叠时按完整路径去重。`extensions` 与 `SearchText` 的规则相同，省略或为空数组时不限制后缀。

匹配按字面文本进行，不解释正则。`ignoreCase` 为真时忽略大小写，缺省区分大小写。每个文件替换全部不重叠匹配，单次扫描，替换文本里出现 `pattern` 不会再次匹配。匹配前把文件内容与 `pattern` 的换行统一为 `\n`，写回时把 `replacement` 的换行转换为该文件首处换行的风格，未匹配内容保持原样。区分大小写时 `pattern` 与 `replacement` 相同会拒绝；忽略大小写时允许，用于统一大小写，实际没有变化时不写入。

写回默认保留每个文件检测到的编码与 BOM，识别 UTF-8、UTF-16 与 UTF-32 的 BOM，没有 BOM 时按 UTF-8 无 BOM。`encoding` 给出时所有写回文件使用该编码，支持 `utf-8`、`utf-8-bom`、`utf-16`、`utf-16be`。

每个候选文件整段读入内存后匹配与写回。递归跳过路径准入规则命中的目录、重解析点目录与二进制文件。单个文件读取或写入失败时记录失败并继续处理其余文件，没有回滚；无法按检测到的编码解码的文件按读取失败处理。`dryRun` 为真时只报告将发生的替换，不写入文件。

输出上限 8000 字符。扫描的文件数与替换处数写在逐文件明细前，明细超过上限时截断。已修改文件按相对路径列出替换处数与匹配起始行，同一行的多处只列一个行号。

## 文本

`ReadFile` 按 UTF-8 解码，带 BOM 时识别。`lineNumbers` 缺省为真，读取输出的每行是 `{行号} |{内容}` 后接该行在文件中的原始终止符，未被单行上限截断时 CRLF、CR、LF 按行保留，所选范围的末行也写出其终止符；文件末行本身没有终止符时不写；以终止符结尾的文件在终止符之后还有一个空行，该空行没有终止符。`lineNumbers` 为假时只输出每行的 `{内容}` 与原始终止符，不输出行号与 ` |` 分隔符。`maxChars` 是正文总字符上限，缺省 10000，允许 1 到 50000，超出 50000 拒绝；正文含行号、保留的行内容、保留的终止符与单行截断标注，不含范围标记与正文前提示。`maxLineChars` 是单行行长上限，缺省 300，只要求大于 0。行长含行内容与终止符，CRLF 计 2 个字符，CR 与 LF 各计 1 个字符，文件末行没有终止符计 0。行长超过上限时保留行内容前缀，丢弃余下内容与终止符，在内容后标注 `（本行共 N 字符，已截断）`，N 为原始行长，截断不切开代理对。截断行不输出终止符，下一行直接接在标注之后。输出文本整体以 `<<<KUROE_TEXT_BEGIN>>>` 开头，以 `<<<KUROE_TEXT_END>>>` 结尾，结束标记后不追加换行；文本以终止符结尾时结束标记位于下一行，否则与末行正文同行。文件没有内容时只返回提示，不带范围标记。工具生成的总截断提示、文件尾提示与行号范围提示使用 LF，并位于开始标记之前；行内截断标注位于行内容之后。行号与请求范围一致并按末行位数右对齐。起始行超出文件长度时拒绝并提示。到达文件尾时正文前给出实际返回的行号范围，正文超过 `maxChars` 字符时截断并在正文前提示，截断不切开 CRLF 与代理对，截断时不报文件尾。目录列表超过 200 条时截断。

`WriteFile` 的写回编码由 `encoding` 指定，支持 `utf-8`、`utf-8-bom`、`utf-16`、`utf-16be`，缺省 `utf-8` 不带 BOM。`ReplaceText` 的写回编码缺省保留各文件检测到的编码与 BOM。`WriteFile` 的 `content` 上限 40000 字符，`ReplaceText` 的 `pattern` 与 `replacement` 各自上限 40000 字符。写入超过上限时整次调用拒绝。

文件信息的时间按本地时区输出，属性只报只读、隐藏、系统、归档。
