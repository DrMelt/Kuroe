# KuroeInfo

`KuroeInfo` 是只读查询工具组，读取当前状态并交回文本，不产生状态改动。凭据不交给模型，目录工具只报凭据是否已设置。

## 函数

| 函数                     | 参数               | 作用                                                   |
| ------------------------ | ------------------ | ------------------------------------------------------ |
| `KuroeInfo/ListTasks`    | 无                 | 列出全部用户任务：编号、标题、状态、节点进度与执行数   |
| `KuroeInfo/GetTask`      | `taskId` 必填      | 查看任务详情：目标、流程、执行节点状态与执行列表       |
| `KuroeInfo/GetExecution` | `executionId` 必填 | 查看执行详情：请求次数、token 用量与上下文            |
| `KuroeInfo/GetCatalog`   | 无                 | 查看提供商、端点、凭据是否已设置、已注册模型的本地名与提供商模型名、当前模型 |
| `KuroeInfo/ListFlows`    | 无                 | 列出流程模板：流程名、执行节点路径与说明               |
| `KuroeInfo/GetFlow`      | `flowName` 必填    | 查看指定流程的展开节点表：模型、节点类型名与要求       |
| `KuroeInfo/GetConfig`    | 无                 | 查看生效配置：各节设置项的生效值与来源标记             |
| `KuroeInfo/ListTools`    | 无                 | 列出内置对话放行的路径前缀与配置的命令工具             |

## 行为

任务与执行查询只覆盖用户任务，内置对话任务不出现。`GetTask` 的任务键可用完整键或末尾 8 位。`GetExecution` 的执行号是数字。执行详情给出请求次数、token 用量与上下文，运行中为当前累计，收口后为最终值，缓存输入、推理 token 与未提供用量的请求数作为明细给出，provider 未返回用量时显示未提供。上下文取最近一次返回用量的请求的输入 token 数，不随请求累计；该请求没有给出输入 token 数，或其后有请求未返回用量时显示未提供。任务与执行详情里的过程记录只给最近 10 条，更早的只报条数。

`ListTools` 只在 Console 内置助手中提供，列出对话白名单与 `.kuroe/tools.json` 声明的命令工具，见[内置助手](../../console/内置助手.md)。
