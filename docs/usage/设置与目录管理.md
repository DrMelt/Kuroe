# 设置与目录管理

## 偏好设置

偏好只有两个来源：代码默认值与工作目录 `.kuroe/` 下的 `settings.json`，后者由两个入口的设置写入命令写入，也可以手工编辑。路径按 `<节>:<设置项>` 书写，如 `Runtime:Temperature`，大小写不敏感，未定义的路径被拒绝。命令见[命令参考](../console/命令参考.md)与[命令行接口](../cli/命令行接口.md)。

```json
{
  "Runtime": {
    "Temperature": 0.7,
    "MaxOutputTokens": 1024,
    "LogLevel": "Warning",
    "MaxConcurrentExecutions": 4
  },
  "Assistant": {
    "Language": "中文"
  }
}
```

两个入口的写入命令都先把值按 JSON 字面量解析，不是合法 JSON 时按字符串写入。`Runtime:Model` 只由模型选择命令维护。

| 路径 | 含义 | 默认 | 作用范围 |
| --- | --- | --- | --- |
| `Runtime:Model` | 当前选用的模型，见[模型接入](模型接入.md) | 未设置 | 两个入口 |
| `Runtime:LogLevel` | 日志级别，改动重启后生效 | `Warning` | 两个入口 |
| `Runtime:Temperature` | 采样温度 | 未设置 | 两个入口 |
| `Runtime:MaxOutputTokens` | 单轮回复的 token 上限 | 未设置 | 两个入口 |
| `Runtime:MaxConcurrentExecutions` | 同时在跑的执行数上限，超出的排队等待，改动即时生效 | `4` | 两个入口 |
| `Assistant:Language` | 内置助手的回复语言，作为系统指令的一部分，已有对话任务需用 `/reset` 重建后生效 | `中文` | Kuroe.Console |

`Assistant:Language` 的值是语言名称，如 `中文`、`English`，空白值被拒绝。修改后不会自动重建对话任务，见[内置助手与专属工具](../console/内置助手与专属工具.md)。两个入口的配置打印命令都会列出全部生效配置，并标记各项是否已写入用户层。命令见[命令参考](../console/命令参考.md)与[命令行接口](../cli/命令行接口.md)。
