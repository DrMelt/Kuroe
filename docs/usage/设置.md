# 设置

## 偏好设置

偏好只有两个来源：代码默认值与工作目录 `.kuroe/` 下的 `settings.json`，后者由两个入口的设置写入操作写入，也可以手工编辑。路径按 `<节>:<设置项>` 书写，如 `Runtime:LogLevel`，大小写不敏感，未定义的路径被拒绝。文件中不再支持的项原样保留，不生效。菜单见[操作指南](../console/操作指南.md)，命令见[命令行接口](../cli/命令行接口.md)。

```json
{
  "Runtime": {
    "LogLevel": "Warning"
  },
  "Assistant": {
    "Language": "中文"
  }
}
```

两个入口的写入操作都先把值按 JSON 字面量解析，不是合法 JSON 时按字符串写入。`Runtime:Model` 只由模型选择维护。

| 路径 | 含义 | 默认 | 作用范围 |
| --- | --- | --- | --- |
| `Runtime:Model` | 当前选用的模型，见[模型接入](模型接入.md) | 未设置 | 两个入口 |
| `Runtime:LogLevel` | 日志级别，改动重启后生效 | `Warning` | 两个入口 |
| `Assistant:Language` | 内置助手的回复语言，作为系统指令的一部分，已有对话任务需在「Kuroe 助手」页选择「重置对话」后生效 | `中文` | Kuroe.Console |

`Assistant:Language` 的值是语言名称，如 `中文`、`English`，空白值被拒绝。修改后不会自动重建对话任务，见[内置助手](../console/内置助手.md)。两个入口的配置查看都会列出全部生效配置，并标记各项是否已写入用户层。菜单见[操作指南](../console/操作指南.md)，命令见[命令行接口](../cli/命令行接口.md)。
