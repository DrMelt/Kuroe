# 设置

## 偏好设置

偏好只有两个来源：内置默认值与工作目录 `.kuroe/` 下的 `settings.json`。文件由两个入口的设置写入操作维护，也可以手工编辑。路径按 `<节>:<设置项>` 书写，如 `Runtime:LogLevel`，大小写不敏感，未定义的路径被拒绝。

```json
{
  "Runtime": {
    "LogLevel": "Warning"
  },
  "Assistant": {
    "Language": "中文"
  },
  "Network": {
    "Proxy": "system"
  }
}
```

值按 JSON 字面量解析，不是合法 JSON 时按字符串写入。

| 路径                 | 含义                                                                                                      | 默认      | 作用范围      |
| -------------------- | --------------------------------------------------------------------------------------------------------- | --------- | ------------- |
| `Runtime:Model`      | 当前选用的本地模型名，见[模型接入](模型接入.md)                                                           | 未设置    | 两个入口      |
| `Runtime:LogLevel`   | 日志级别，改动重启后生效                                                                                  | `Warning` | 两个入口      |
| `Assistant:Language` | 内置助手的回复语言，已有对话任务需重置对话后生效                                                          | `中文`    | Kuroe.Console |
| `Network:Proxy`      | 代理模式，改动重启后生效。`system` 使用系统代理，`direct` 直连，绝对地址使用指定代理；未设置时同 `system` | 未设置    | 两个入口      |

`Assistant:Language` 的值是语言名称，如 `中文`、`English`，空白值被拒绝，生效方式见[内置助手](../console/内置助手.md)。模型选择只经模型目录维护，设置页与 `config set` 都不写 `Runtime:Model`。

## 网络代理

`Network:Proxy` 支持以下取值：

| 值       | 行为                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 未设置   | 使用系统代理，效果与 `system` 相同                                                                                       |
| `system` | 使用系统代理。Windows 取 WinINET 或 IE 的系统代理，macOS 取系统网络代理，Linux 取 `http_proxy`、`https_proxy` 等环境变量 |
| `direct` | 不使用代理，全部直连                                                                                                     |
| 绝对地址 | 使用指定代理，支持 `http`、`https`、`socks4`、`socks4a`、`socks5`。地址中的用户名与密码作为代理凭据                      |

`Network:Proxy` 的改动在重启后生效。

代理只作用于 Kuroe 进程内的模型请求，不作用于 git、dotnet 与命令节点启动的子进程。子进程需要按各自的方式配置代理。

代理凭据在 `.kuroe/settings.json` 中为明文，不要提交。

```powershell
dotnet Kuroe.Cli.dll config set Network:Proxy system
dotnet Kuroe.Cli.dll config set Network:Proxy direct
dotnet Kuroe.Cli.dll config set Network:Proxy http://127.0.0.1:7890
dotnet Kuroe.Cli.dll config unset Network:Proxy
```

`config set` 的值不是合法 JSON 时按字符串写入。`config unset Network:Proxy` 删除用户层设置，回到未设置状态，效果与 `system` 相同。
