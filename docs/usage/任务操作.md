# 任务操作

## 任务与 run

任务是长期会话线程：有自己的对话历史，前台对话写入这个任务。提交任务时按流程模板建任务，流程由节点组成：执行节点的模型选择由装配层输入，能力工具与指令在节点上声明，run 的上下文由上游装配后传入，不继承未声明的内容。

内置流程是制定计划 → 分配执行：制定计划交回条目拆分，分配执行按条目各启动一个 run 实施。

`/task new <目标>` 按默认流程提交任务；指定流程用 `/task new --flow <流程> <目标>`。

## 查看

`/task` 打开任务浏览器：任务列表 → 任务内已执行与在跑的 run → run 的详情，逐级进入，用 `Esc` 或选择「返回」退一级。列表同时给出在跑与已启动的 run 数，详情可跳转到装配时引用的上游 run。

后台 run 的过程不写入终端，只在状态变化时输出一行通知；`/task show <任务号>` 与 `/task run <run号>` 是不进任务浏览器的等价查看方式。

`/flow show <流程>` 打印节点的层级、产出的契约、展开方式、上游引用与放行规则。

## 等待批准与返工

任务停在待批准或失败时，任务浏览器里直接给出批准、返工、取消这几个动作，对应的命令见[命令参考](命令参考.md)。

- `Gate: Review` 的执行节点产出后停在待批准，`/task approve <任务号>` 才进入下一步。按条目展开的执行节点每个条目的 run 各自停在待批准，可以用 `/task approve <任务号> run <run号>` 逐个批准，最后一个批准后节点才放行下游。
- 执行节点失败或未收口时停在阻塞，`/task rework <任务号>` 重跑阻塞的目标。

## 等待输入

`Output: Input` 的输入节点不启动 run：依赖齐备后停在待输入，任务停在「待输入」状态。用 `/task answer <任务号> [<@节点名>] <文本>` 回答，回答即该节点产出放行下游；多个待输入节点并存时必须用 `@节点名` 点名单个节点，唯一待输入节点时无需点名，回答文本首词即使与节点名相同也原样保留。回答会随下游 run 装配进入上下文，取消任务可随时终止等待。

## 收口上限

超出时不报错，按下列方式收口，都不需要通过配置调整：

| 位置                   | 上限                                      | 超出后                                                 |
| ---------------------- | ----------------------------------------- | ------------------------------------------------------ |
| 过程记录               | 400 条                                    | 丢最早的记录，`/task show` 与 run 详情里标出被丢的条数 |
| 详情视图里的过程记录   | 最近 40 条                                | 更早的只报条数                                         |
| 过程记录里的一段文本   | 4096 字                                   | 另起一段，避免逐字增量反复拷贝整段                     |
| 装配进上下文的单条内容 | 2000 字                                   | 截断并加省略号                                         |
| `ContextOutput` 端口注入的内容 | 逐条 2000 字                              | 与装配内容同限，并按上下文帧计为多条                 |
| 带进上下文的任务对话   | 最近 6 条                                 | 更早的内容由上游产出概括                               |
| 任务标题               | 40 字                                     | 取目标首行截断                                         |
| 一个方案的条目         | 20 条                                     | 提交被拒绝，模型在同一轮里改正                         |
| 节点执行次数           | 100 次，执行节点与容器可用 `MaxRuns` 配置 | 达到上限不再重跑，未成功的路径停在阻塞                 |
