# 安装与运行

从零完成第一个任务见[Console 快速上手](../console/快速上手.md)与[CLI 快速上手](../cli/快速上手.md)。本篇给两个入口共用的环境、产物与工作目录说明。从源码构建见[从源码构建](从源码构建.md)，入口差异见[入口与分工](入口与分工.md)。

## 环境要求

目标机需要 .NET 10 运行时。交互终端要求只属于 Kuroe.Console，见[Console 快速上手](../console/快速上手.md)；Kuroe.Cli 不提供交互，也不读取 stdin，见[CLI 快速上手](../cli/快速上手.md)。

## 安装

从 release 页面下载编译产物压缩包，解压到任意目录。压缩包内含 `Kuroe.Console.dll` 与 `Kuroe.Cli.dll`，产物与操作系统和处理器架构无关，Windows、Linux、macOS 共用同一份。

## 运行入口

| 入口 | 用途 | 说明 |
| --- | --- | --- |
| Kuroe.Console | 交互终端、内置助手与任务浏览 | 见[Console 快速上手](../console/快速上手.md) |
| Kuroe.Cli | 脚本与 CI 的一次性调用 | 见[CLI 快速上手](../cli/快速上手.md) |

两个入口的启动参数都由 System.CommandLine 解析，`-d` 省略时用启动进程的当前目录，`-h` 打印用法，参数错误以非零退出码结束。平台相关的运行环境：内置 git 工具与 dotnet 工具调用 PATH 中的同名程序；命令模板工具的输出按 UTF-8 解码。

## 工作目录

工作目录的 `.kuroe/` 下存放四个配置文件：

| 文件            | 内容                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------- |
| `settings.json` | 偏好设置，见[设置与目录管理](设置与目录管理.md)                                           |
| `catalog.json`  | 提供商、模型及其凭据，含明文凭据，不要提交                                                |
| `flows.json`    | 任务流程模板，见[流程文件与节点库](流程文件与节点库.md)                                   |
| `tools.json`    | 命令模板工具，见[工具扩展](工具扩展.md)；含命令执行声明，来源不可信的工作目录不要直接运行 |

两个入口的命令里的文件参数相对该工作目录解析，与启动时的进程当前目录无关。

### 任务目录

`.kuroe_tasks/` 下是用户任务的工作目录，两个入口提交任务时建立，名字为 `任务号-流程-标题`，例如 `0003-审阅-修复登录超时`。

- 任务号四位定宽，超过四位自然增长。
- 流程与标题在创建时取一次；流程段不含连字符，标题段可以含；非法字符与控制字符替换为下划线，流程段截到 20 字符，标题段截到 40 字符。
- 启动时按已有任务目录的最大号加一续号，同名目录不会被复用。

任务状态的生命周期按入口不同：Console 的任务由「任务」菜单管理，见[任务操作](../console/任务操作.md)；CLI 的 `run` 只在提交进程内推进，进程退出后任务状态消失，目录保留，见[命令行接口](../cli/命令行接口.md#run)。

## 产物目录

产物目录的 `source/` 下是构建时的仓库源码与文档，保留仓库相对路径：`Source/` 与 `Tests/` 下的 `.cs`、`.csproj`，`Source/SourceExport.props`，`docs` 下的 `.md` 以及根目录的几个文件，生成物与 `.docs` 参考资料不入内。该目录只在工具面上提供读取，由 Kuroe.Console 以它的位置装配 `source` 工具组，见[内置助手与专属工具](../console/内置助手与专属工具.md)。Kuroe.Cli 不装配该工具组，也不读取该目录。
