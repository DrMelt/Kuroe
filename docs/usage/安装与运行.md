# 安装与运行

从零完成第一个任务的步骤见[快速上手](快速上手.md)，本篇给环境、产物与工作目录的完整说明。从源码构建见[从源码构建](从源码构建.md)。

## 环境要求

目标机需要 .NET 10 运行时；以及可读键盘的交互终端——浏览任务与执行依赖键盘选择，输入被重定向时程序拒绝启动。

## 安装

从 release 页面下载编译产物压缩包，解压到任意目录。产物与操作系统和处理器架构无关，Windows、Linux、macOS 共用同一份。

## 运行

在产物目录执行：

```powershell
dotnet Kuroe.Cli.dll -d <工作目录>
```

`-d` 省略时用启动进程的当前目录。启动参数由 System.CommandLine 解析，`-h` 打印用法，参数错误以非零退出码结束。程序按自身位置定位 `source/`，与进程当前目录无关。

平台相关的运行环境：内置 git 工具与 dotnet 工具调用 PATH 中的同名程序；命令模板工具的输出按 UTF-8 解码。

## 工作目录

工作目录的 `.kuroe/` 下存放四个配置文件：

| 文件            | 内容                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------- |
| `settings.json` | 偏好设置，见[设置与目录管理](设置与目录管理.md)                                           |
| `catalog.json`  | 提供商、模型及其凭据，含明文凭据，不要提交                                                |
| `flows.json`    | 任务流程模板，见[流程文件与节点库](流程文件与节点库.md)                                   |
| `tools.json`    | 命令模板工具，见[工具扩展](工具扩展.md)；含命令执行声明，来源不可信的工作目录不要直接运行 |

`.kuroe_tasks/` 下是各任务的工作目录，由 `/task new` 建立，命名与生命周期见[任务操作](任务操作.md#任务工作目录)。

命令里的文件参数（`/catalog export|import`、`/flow add`）相对该工作目录解析，与启动时的进程当前目录无关。

## 产物目录

产物目录的 `source/` 下是构建时的仓库源码与文档，保留仓库相对路径：`Source/` 与 `Tests/` 下的 `.cs`、`.csproj`，`docs` 下的 `.md` 以及根目录的几个文件，生成物与 `.docs` 参考资料不入内。该目录只在工具面上提供读取，宿主以它的位置装配 `source` 工具组，见[工具扩展](工具扩展.md#导出资料工具)。
