# 流程文件与节点库

流程模板存在工作目录 `.kuroe/` 的 `flows.json`，可以手工编辑。文件不存在时流程库为空。节点分为两层：顶层节点库定义可复用的节点，每条流程用一个根节点把节点装配成图。节点库由程序内置节点与文件顶层 `Nodes` 同名合并，以文件定义覆盖。加载时校验：节点库不合法时只报节点库错误，节点库合法时逐条流程校验并一次给全。导入的文件必须能独立装配，流程引用的节点要来自内置节点或写在同一文件里；导入策略按入口不同，见[入口与分工](入口与分工.md)、[命令参考](../console/命令参考.md)与[命令行接口](../cli/命令行接口.md)。

文件由 JSON 格式层读成描述文档，再由编译器构造模型、展开节点库并编译执行视图。JSON 层只负责文本与描述文档之间的绑定，不构造节点模型，也不判断模型不变量。编译管线见[流程编译管线](../architecture/流程编译管线.md)。

节点对象的字段见[节点定义](节点定义.md)，流程的引用与接线见[流程装配](流程装配.md)。

文件结构：

```json
{
  "Nodes": [
    { "Name": "库节点名", "Kind": "Llm", ... }
  ],
  "Flows": [
    {
      "Name": "流程名",
      "Description": "可选说明",
      "Models": [],
      "Start": { "Outputs": [{ "Name": "目标", "Type": "Text" }, { "Name": "背景", "Type": "Text", "Value": "固定背景" }] },
      "Nodes": [
        {
          "Name": "根容器名",
          "Kind": "Container",
          "Nodes": []
        }
      ]
    }
  ]
}
```

## 节点库

顶层 `Nodes` 是节点定义，作为复用单元供流程引用。节点定义有两个来源：程序内置节点随启动提供，文件顶层 `Nodes` 定义自定义节点。两者同名合并，以文件定义覆盖；同一文件内顶层节点名重复报错。内置节点是执行节点「规划」「执行」与容器「交付」。

两种定义：

- **执行节点定义**：声明输入端口、输出端口、工具白名单与执行方式，不写接线，不声明模型。
- **容器定义**：`Nodes` 子数组组织一组有序成员，`Models` 声明成员需要的模型槽位，成员用 `Model` 写槽位名；`Inputs` 声明传入端口，成员可用 `@端口名` 引用传入内容，输入端口不写 `Default`；`Outputs` 声明命名输出端口，条目写 `Name` 与 `Ref`，把内部成员产出透出为容器对外接口。

节点定义的对象形状见[节点定义](节点定义.md)；库定义只声明能力，模型与接线由装配层输入。

## 开始入口

`Start` 声明流程唯一的来源节点，节点名与节点标签都是保留的 `Start`：`Outputs` 条目写 `Name`、`Type` 与可选 `Value`，`Type` 只能是 `Text`。恰好一个端口不带 `Value`，承接提交任务时给出的初始输入；其余端口必须带 `Value`，固定输出配置里写死的文本。开始节点不属于任何容器，流程树内任何作用域都能引用，节点用 `From: [{ "输入名": "Start@端口" }]` 接线取用。节点库定义内仍受自包含约束，成员只能引用子树内节点或本容器 `Inputs` 声明的端口，需要任务目标时由引用处在 `In` 里把输入端口绑到 `Start@端口`。流程内节点名与节点标签、库定义名都不能用保留的 `Start`。

每个执行节点与输入节点都必须能从开始经 `From` 引用边到达，否则加载报错。引用接线的规则见[流程装配](流程装配.md#上游接线)。

## 校验规则

启动时逐条校验。格式层先判 JSON 语法、键名与字段类型，构造层再判文档形状与类型参数，库装配层判节点库与引用展开，模型层与图层判运行期不变量。任一层失败即返回该层全部错误，后续层不再执行。节点库不合法时只报节点库错误，不再校验流程；节点库合法时逐条流程校验，全部非法项一次给出。规则即任务推进依赖的不变量，下列规则属于库定义与文件装载，节点形状规则见[节点定义](节点定义.md#校验规则)，引用、展开与环的规则见[流程装配](流程装配.md#校验规则)：

- 节点库名非空且库内唯一，节点库定义不能是引用，节点名不能是流程起点的保留名 `Start`。
- 节点库执行定义不声明模型，容器定义用 `Models` 声明槽位，组内执行成员必须写容器声明的槽位名。
- 执行节点库定义声明输入端口与输出端口，`Text` 输入端口可写 `Default`，不写 `From`、`In` 与容器形状的 `Outputs` 条目。
- 容器定义不写执行配置、`From`、`In` 与 `Validate`，输入端口不写 `Default`，也不接受任何类型参数。
- 容器定义自包含：成员 `From` 只指向定义内部节点或已声明端口，至少要包含一个执行节点。
