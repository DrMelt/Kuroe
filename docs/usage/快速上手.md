# 快速上手

从环境准备到完成第一个任务的最短路径。产物获取与运行细节见[安装与运行](安装与运行.md)，从源码构建见[从源码构建](从源码构建.md)。

## 环境与依赖

需要 .NET 10 运行时，以及可读键盘的交互终端——浏览任务与执行依赖键盘选择，输入被重定向时程序拒绝启动。从 release 页面下载编译产物压缩包并解压。

## 启动

在产物目录执行：

```powershell
dotnet Kuroe.Cli.dll -d <工作目录>
```

`-d` 省略时用启动进程的当前目录。

## 注册模型

工作目录里还没有提供商与模型，先注册再接通：

```text
/provider add openai https://api.openai.com/v1 sk-xxxx
/model add <模型> openai
/model <模型>
```

提供商是模型的宿主，有名字、端点与凭据；模型注册到提供商名下。`<模型>` 是本地给模型注册的名字，与模型实际使用的名字无关，例如：

```text
/model add gpt-4o openai
/model gpt-4o
```

未选择模型也能启动；提交任务或发起对话时才需要，未写或未注册时报错。

## 提交第一个任务

```text
/flow list
/task new --flow <流程> 写一段百字以内的欢迎致辞
/task
```

流程来自工作目录 `.kuroe/flows.json`，也可以用 `/flow add <文件>` 导入示例文件；`/flow list` 列出全部流程名。`/task new --flow <流程> <目标>` 按给定流程提交任务；`/task` 打开任务浏览器逐级查看执行的进展。普通输入进入常驻对话任务，随时可答，不需要任务在前台，见[命令参考](命令参考.md)。

## 输出形态

终端输出按用途分两种框：助手回合与详情列表用方角框，等待按键的选择与确认用圆角框。框标题写内容名，不加标记；启动横幅不带标题。任务浏览的每一层以 `──` 横线标题划出层级，标题写成进入路径。单行提示、错误与流式文本不进框。
