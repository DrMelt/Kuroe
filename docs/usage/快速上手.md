# 快速上手

从环境准备到完成第一个任务的最短路径。环境与运行细节见[安装与运行](安装与运行.md)。

## 环境与依赖

需要 .NET SDK 10.0，以及可读键盘的交互终端——浏览任务与 run 依赖键盘选择，输入被重定向时程序拒绝启动。

ApiHub 未发布到 nuget.org，`nuget.config` 的 local 源指向仓库内的 `packages/`，该目录不入库。克隆后在仓库根目录下载 release 的四个包：

```powershell
$ver = '0.2.0'
'ApiHub', 'ApiHub.ChatClient', 'ApiHub.Json', 'ApiHub.Shared' | ForEach-Object {
    Invoke-WebRequest "https://github.com/DrMelt/ApiHub/releases/download/v$ver/$_.$ver.nupkg" -OutFile "packages/$_.$ver.nupkg"
}
```

## 启动

```powershell
dotnet run --project Kuroe.Cli -- -d <工作目录>
```

`-d` 省略时用启动进程的当前目录。

## 注册模型

工作目录里还没有提供商与模型，先注册再接通：

```text
/provider add openai https://api.openai.com/v1 sk-xxxx
/model add <模型> openai
/model <模型>
```

提供商是模型的宿主，有名字、端点与凭据；模型注册到提供商名下。`<模型>` 是本地给模型注册的名字，与模型实际使用的名字无关，例如：

```text
/model add gpt-4o openai
/model gpt-4o
```

未选择模型也能启动；提交任务或发起对话时才需要，未写或未注册时报错。

## 提交第一个任务

```text
/task new 写一段百字以内的欢迎致辞
/task
```

`/task new` 提交任务，按默认流程「制定计划 → 分配执行」启动 run；`/task` 打开任务浏览器逐级查看 run 的进展。普通输入进入常驻对话任务，随时可答，不需要任务在前台，见[命令参考](命令参考.md)。
