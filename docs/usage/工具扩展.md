# 工具扩展

## 工具载体

模型可调用的能力由工具载体声明。实现 `ITool` 的类提供 `Functions`：一组 `ToolFunction` 声明，每个声明给出函数名、说明、参数与调用体。

```csharp
public sealed class TimeTool : ITool
{
    public IReadOnlyList<ToolFunction> Functions { get; } =
    [
        new ToolFunction(new ToolName("GetLocalTime"), "获取当前系统时区的准确当地时间", [],
            _ => $"当前系统时间是：{DateTime.Now:yyyy-MM-dd HH:mm:ss}"),
    ];
}
```

`ToolParameter` 声明参数：名字、给模型的说明、是否布尔值与是否必填。宿主按声明拼装参数的 JSON Schema，随请求交给模型。调用体把结果文本交回模型，拒绝也写成文本。

需要按回合绑定的工具实现 `IScopedTool`，`ForTurn` 返回绑定到该回合的载体，过程记录与提交身份据此归属。

## 工具面

每个执行节点能用的工具是节点 `Tools` 白名单声明的能力工具，另按产出契约自动附上契约工具：规划节点给 `SubmitPlanItems`，检查节点给 `SubmitVerdict`。前台对话给全部工具。

新增工具在 `ServiceCollectionExtensions.AddKuroe` 注册为 `ITool`：

```csharp
services.AddSingleton<ITool>(new TimeTool());
services.AddSingleton<ITool, PlanTool>();
```

内置的 `GetLocalTime`、`GetWeather` 是示例工具，后者为占位实现。契约工具 `SubmitPlanItems`、`SubmitVerdict` 对应[流程节点配置](流程节点配置.md)里的 `Output: Plan` 与 `Output: Review`。
