# 工具扩展

## 工具载体

模型可调用的能力由工具载体声明。实现 `ITool` 的类提供 `Functions`：一组 `ToolFunction` 声明，每个声明给出函数名、说明、参数与调用体，可另给工具路径 `Path` 声明层级。函数名是模型调用名，工具路径是白名单匹配用的层级身份，形如 `层级/函数名`；未声明路径时即函数名。

```csharp
public sealed class TimeTool : ITool
{
    public IReadOnlyList<ToolFunction> Functions { get; } =
    [
        new ToolFunction(new ToolName("GetLocalTime"), "获取当前系统时区与准确当地时间", [],
            _ =>
            {
                DateTimeOffset now = DateTimeOffset.Now;
                return $"当前系统时间是：{now:yyyy-MM-dd HH:mm:ss}，时区 UTC{now:zzz}";
            }),
    ];
}
```

`ToolParameter` 声明参数：名字、给模型的说明、是否布尔值与是否必填。宿主按声明拼装参数的 JSON Schema，随请求交给模型。调用体把结果文本交回模型，拒绝也写成文本。

需要按回合绑定的工具实现 `IScopedTool`，`ForTurn` 返回绑定到该回合的载体，过程记录与提交身份据此归属。

## 工具面

每个执行节点能用的工具是节点 `Tools` 白名单声明的能力工具，另按产出契约自动附上契约工具：规划节点给 `SubmitPlanItems`。白名单按工具路径前缀匹配：写上级路径即放行该路径下的整棵子树，写完整路径只放行单个函数。匹配按原文大小写敏感；非法路径（段为空、含空白或花括号，或以 `/` 开头结尾）匹配不到任何工具，节点白名单里写非法路径在流程装配时报错。前台对话给固定节点配置白名单声明的能力工具，未列入白名单的工具不可用。

内置信息查询工具整组在 `info` 下：`info/ListTasks`、`info/GetTask`、`info/GetRun`、`info/GetActiveTask`、`info/GetCatalog`、`info/ListFlows`、`info/GetFlow`、`info/GetConfig`、`info/ListTools`。前台对话白名单写 `info` 即整组放行，另放行 `GetLocalTime`。它们只从各服务的只读快照取数交回文本，供用户直接问"现在有哪些任务"这类自然语言查看 Kuroe 状态，是斜杠命令之外的另一种操作方式；凭据不交给模型，目录工具只报凭据是否已设置。信息查询工具默认不进执行节点的工具面，需要时在节点 `Tools` 白名单里显式声明，可写 `info` 整组放行。

内置文件访问工具整组在 `files` 下：`files/ReadFile` 读取工作目录内文本文件指定行号范围的内容，`from` 与 `to` 是行号，缺省读前 50 行，`to` 超出文件行数时读到文件尾；`files/ReadFiles` 一次读取多个文本文件，`paths` 是相对路径列表，结果按列表顺序分段交回，单条错误不阻断其它条目；`files/WriteFile` 把文本覆盖写入工作目录内文件，文件已存在时直接覆盖，`content` 为空时生成空文件，上限 40000 字符，父目录缺失时自动创建，`encoding` 指定写回编码、缺省 `utf-8` 不带 BOM、支持 `utf-8`、`utf-8-bom`、`utf-16`、`utf-16be`；`files/PatchFile` 按 `from`/`to` 行号范围替换文件内容，`original` 必须是该范围现在的原文、与文件逐行不一致时拒绝并回给实际内容，`replacement` 行数可增减、为空时删除该范围，写回统一换行符，编码按 `encoding` 参数、缺省 `utf-8` 不带 BOM；`files/ListDirectory` 列出工作目录内目录的直接子项，`path` 缺省时列出工作目录根。路径是相对工作目录的写法，解析后必须落回工作目录内，`..` 与绝对路径逃出时调用被拒绝；校验按路径字符串进行，不解析目录联接点与符号链接，工作目录内指向外部的链接不在边界保护内；文本按 UTF-8 解码，带 BOM 时按 BOM 识别。单个文件超 8000 字符截断，批量读取整体超 40000 字符截断，目录列表超 200 条截断。前台对话白名单写 `files` 即整组放行；执行节点需要时在节点 `Tools` 白名单里显式声明。

## 命令模板工具

不想写代码也能加工具：在工作目录 `.kuroe/tools.json` 里声明命令工具，模板以参数项数组给出，启动时按定义注册进工具面。每项可以是字符串或对象：字符串按现状，占位符用 `{参数名}`；对象 `{ "Text": "...", "OmitWhenMissing": "参数名" }` 把参数项与参数显式关联，关联参数缺省时整个参数项消失。文件不存在时没有命令工具，条目不合法时启动报错。上例 RunDiff 与 RunLog 同属 `git` 分组，完整路径分别是 `git/RunDiff` 与 `git/RunLog`；节点 `Tools` 白名单写 `git` 即可同时放行，写 `git/RunDiff` 只放行一个。

```json
{
  "Tools": [
    {
      "Name": "RunDiff",
      "Path": "git",
      "Description": "查看指定文件或目录相对 HEAD 的改动。",
      "Template": ["git", "diff", "{path}"],
      "Parameters": [
        { "Name": "path", "Description": "要查看的文件或目录路径", "Required": true }
      ]
    },
    {
      "Name": "RunLog",
      "Path": "git",
      "Description": "查看指定文件列表的提交历史。",
      "Template": ["git", "log", "--oneline", "--", "{files}"],
      "Parameters": [
        { "Name": "files", "Description": "限定查看的文件路径列表", "List": true }
      ]
    },
    {
      "Name": "RunCurl",
      "Description": "携带可省略的访问令牌请求一个 URL。",
      "Template": ["curl", "-f", { "Text": "Authorization: Bearer {token}", "OmitWhenMissing": "token" }, "{url}"],
      "Parameters": [
        { "Name": "token", "Description": "访问令牌，可省略" },
        { "Name": "url", "Description": "请求地址", "Required": true }
      ]
    }
  ]
}
```

| 字段            | 类型     | 含义                                             |
| --------------- | -------- | ------------------------------------------------ |
| `Name`          | string   | 函数名，模型按它调用，不能与已注册工具重名 |
| `Path`          | string   | 工具路径的分组部分，完整路径为 `Path/函数名`；省略时完整路径即函数名。节点白名单按完整路径匹配，写上级路径即放行整棵子树 |
| `Description`   | string   | 给模型的说明                                     |
| `Template`      | (string \| object)[] | 命令行模板，数组每一项是一个参数项；对象为 `{ "Text": ..., "OmitWhenMissing": ... }` |
| `Parameters`    | object[] | 参数声明：`Name`、`Description`、`Required`、`List` |
| `Directory`     | string   | 命令执行目录，相对工作目录，缺省为工作目录根；不限制在工作目录内     |
| `TimeoutSeconds`| int      | 命令超时秒数，缺省 120，最大 2147483                 |
| `OutputLimit`   | int      | 交回文本上限，缺省 8000 字符                      |

`Required` 必填的参数缺省时调用被拒绝；可选参数缺省时对应的参数项整体消失。标量参数的缺省指未给出或 JSON null，空字符串是有效值，会原样作为参数项传给命令。

`List` 声明字符串列表参数，模型以数组给出，模板里必须写成独立的 `{files}` 参数项，不传或空数组时该项消失。列表参数不能嵌在其他文字里，如 `"--flag={files}"` 不合法。

模板参数项对象声明缺省省略：`Text` 是命令行文字（可含占位符），`OmitWhenMissing` 是关联参数名。关联参数缺省（未给或 JSON null，列表未给或空数组）时整个参数项从命令行去掉，包括项里的文字；关联参数必填且缺省时调用被拒绝。两个字段都必须给出。字符串项内嵌占位符缺省时仍按现状保留字面量传给命令。

模型调用时替代占位符、在 `Directory` 指向的目录启动进程，stdout 与 stderr 合并成文本交回模型，附退出码；超时或启动失败也写成文本。输出按 UTF-8 解码，老式 Windows 工具按本地代码页输出时文本可能乱码。参数项经进程启动直接传入，不经 shell 解释，模板不支持管道、重定向等 shell 语法。

`tools.json` 声明模型有权调用的命令，是命令执行边界所在；拾取仓库或共享目录前先检查其模板与 `Directory`。模板第一项是程序本身，其余项是参数。不要把占位符嵌进 shell 解释器（`cmd /c`、`bash -c` 等）的命令串里，否则模型实参里的 shell 元字符会被解释，占位符等于拿到任意命令执行能力。

新增工具在 `ServiceCollectionExtensions.AddKuroe` 注册为 `ITool`：

```csharp
services.AddSingleton<ITool>(new TimeTool());
services.AddSingleton<ITool, PlanTool>();
```

内置的 `GetLocalTime` 是示例工具，信息查询与文件访问工具见上面的工具面一节。契约工具 `SubmitPlanItems` 对应[流程节点配置](流程节点配置.md)里的 `Output: Plan`。
