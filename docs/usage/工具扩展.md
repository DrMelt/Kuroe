# 工具扩展

## 工具载体

模型可调用的能力由工具载体声明。实现 `ITool` 的类提供 `Functions`：一组 `ToolFunction` 声明，每个声明给出函数名、说明、参数与调用体，可另给工具路径 `Path` 声明层级。函数名是模型调用名，工具路径是白名单匹配的层级，形如 `层级/函数名`；未声明路径时即函数名。

```csharp
public sealed class TimeTool : ITool
{
    public IReadOnlyList<ToolFunction> Functions { get; } =
    [
        new ToolFunction(new ToolName("GetLocalTime"), "获取当前系统时区与准确当地时间", [],
            _ =>
            {
                DateTimeOffset now = DateTimeOffset.Now;
                return $"当前系统时间是：{now:yyyy-MM-dd HH:mm:ss}，时区 UTC{now:zzz}";
            }),
    ];
}
```

`ToolParameter` 声明参数：名字、给模型的说明、是否布尔值与是否必填。宿主按声明拼装参数的 JSON Schema，随请求交给模型。调用体把结果文本交回模型，拒绝也写成文本。

需要按回合绑定的工具实现 `IScopedTool`，`ForTurn` 返回绑定到该回合的载体，过程记录与提交身份据此归属。

## 工具面

执行节点的工具由 `Tools` 白名单限定：按工具路径前缀匹配，写上级路径即放行整棵子树，写完整路径只放行单个函数，匹配按原文大小写敏感。非法路径（段为空、含空白或花括号，或以 `/` 开头结尾）匹配不到任何工具，写入白名单在流程装配时报错。规划执行节点按 `Output: Plan` 自动附上契约工具 `SubmitPlanItems`。内置对话的回话节点用固定白名单，未列入的工具不可用；白名单写 `info`、`files` 即整组放行，另放行 `GetLocalTime`。

内置信息查询工具整组在 `info` 下：`info/ListTasks`、`info/GetTask`、`info/GetRun`、`info/GetCatalog`、`info/ListFlows`、`info/GetFlow`、`info/GetConfig`、`info/ListTools`。它们从各服务的只读快照读取内容并交回文本，可用自然语言询问 Kuroe 状态；凭据不交给模型，目录工具只报凭据是否已设置。默认不在执行节点的工具面中，需要时在节点 `Tools` 白名单里显式声明。

内置文件访问工具整组在 `files` 下：

| 函数 | 作用 |
| --- | --- |
| `files/ReadFile` | 读取工作目录内文本文件指定行号范围，`from`/`to` 是行号，缺省读前 50 行，超出文件行数读到文件尾 |
| `files/ReadFiles` | 一次读取多个文本文件，结果按 `paths` 顺序分段交回，单条错误不阻断其它 |
| `files/WriteFile` | 覆盖写入文本，`content` 为空时生成空文件，上限 40000 字符，父目录缺失自动创建 |
| `files/PatchFile` | 按 `from`/`to` 行号范围替换内容，`original` 必须是该范围当前原文、不一致时拒绝并回给实际内容，`replacement` 为空时删除该范围，写回统一换行符 |
| `files/ListDirectory` | 列出目录直接子项，`path` 缺省为工作目录根 |

路径是相对工作目录的写法，解析后必须落回工作目录内，`..` 与绝对路径逃出时调用被拒绝；校验按路径字符串进行，不解析目录联接点与符号链接。文本按 UTF-8 解码，带 BOM 时识别。写回编码由 `encoding` 指定，支持 `utf-8`、`utf-8-bom`、`utf-16`、`utf-16be`，缺省 `utf-8` 不带 BOM。单个文件超 8000 字符截断，批量读取整体超 40000 字符截断，目录列表超 200 条时截断。

## 命令模板工具

无需写代码也能加工具：在工作目录 `.kuroe/tools.json` 里声明命令工具，模板以参数项数组给出，启动时按定义注册到工具面；文件不存在时没有命令工具，条目不合法时启动报错。下例 RunDiff 与 RunLog 同属 `git` 分组，完整路径分别是 `git/RunDiff` 与 `git/RunLog`，白名单写 `git` 即整组放行，写 `git/RunDiff` 只放行一个。参数项按字符串或对象区分，写法见[参数规则](#参数规则)。

```json
{
  "Tools": [
    {
      "Name": "RunDiff",
      "Path": "git",
      "Description": "查看指定文件或目录相对 HEAD 的改动。",
      "Template": ["git", "diff", "{path}"],
      "Parameters": [
        { "Name": "path", "Description": "要查看的文件或目录路径", "Required": true }
      ]
    },
    {
      "Name": "RunLog",
      "Path": "git",
      "Description": "查看指定文件列表的提交历史。",
      "Template": ["git", "log", "--oneline", "--", "{files}"],
      "Parameters": [
        { "Name": "files", "Description": "限定查看的文件路径列表", "List": true }
      ]
    },
    {
      "Name": "RunCurl",
      "Description": "携带可省略的访问令牌请求一个 URL。",
      "Template": ["curl", "-f", { "Text": "Authorization: Bearer {token}", "OmitWhenMissing": "token" }, "{url}"],
      "Parameters": [
        { "Name": "token", "Description": "访问令牌，可省略" },
        { "Name": "url", "Description": "请求地址", "Required": true }
      ]
    }
  ]
}
```

| 字段            | 类型     | 含义                                             |
| --------------- | -------- | ------------------------------------------------ |
| `Name`          | string   | 函数名，模型按它调用，不能与已注册工具重名 |
| `Path`          | string   | 工具路径的分组部分，完整路径为 `Path/函数名`；省略时完整路径即函数名。节点白名单按完整路径匹配，写上级路径即放行整棵子树 |
| `Description`   | string   | 给模型的说明                                     |
| `Template`      | (string \| object)[] | 命令行模板，数组每一项是一个参数项，对象写法见[参数规则](#参数规则) |
| `Parameters`    | object[] | 参数声明：`Name`、`Description`、`Required`、`List` |
| `Directory`     | string   | 命令执行目录，相对工作目录，缺省为工作目录根；不限制在工作目录内     |
| `TimeoutSeconds`| int      | 命令超时秒数，缺省 120，最大 2147483                 |
| `OutputLimit`   | int      | 交回文本上限，缺省 8000 字符                      |

### 参数规则

标量参数：`Required` 必填的参数缺省时调用被拒绝，可选参数缺省时对应的参数项整体消失；缺省指未给出或 JSON null，空字符串是有效值，会原样传给命令。

`List` 声明字符串列表参数，模型以数组给出，模板里必须写成独立的 `{files}` 参数项，不传或空数组时该项消失；列表参数不能嵌在其他文字里，如 `"--flag={files}"` 不合法。

模板参数项对象把参数项与参数显式关联：`Text` 是命令行文字（可含占位符），`OmitWhenMissing` 是关联参数名，两个字段都必须给出。关联参数缺省（未给或 JSON null，列表未给或空数组）时整个参数项从命令行去掉，包括项里的文字；关联参数必填且缺省时调用被拒绝。字符串项内嵌占位符缺省时保留字面量原样传给命令。

模型调用时替代占位符、在 `Directory` 指向的目录启动进程，stdout 与 stderr 合并成文本交回模型，附退出码；超时或启动失败也写成文本。输出按 UTF-8 解码，用本地代码页输出的 Windows 工具其文本可能乱码。参数项经进程启动直接传入，不经 shell 解释，模板不支持管道、重定向等 shell 语法。

`tools.json` 声明模型有权调用的命令，是命令执行边界所在，采纳仓库或共享目录前先检查其模板与 `Directory`。模板第一项是程序本身。不要把占位符嵌进 `cmd /c`、`bash -c` 这类 shell 解释器命令串，模型实参里的元字符会被 shell 解释，等同于把任意命令执行能力交给模型。

新增工具在 `ServiceCollectionExtensions.AddKuroe` 注册为 `ITool`：

```csharp
services.AddSingleton<ITool>(new TimeTool());
services.AddSingleton<ITool, PlanTool>();
```

内置的 `GetLocalTime` 是示例工具，信息查询与文件访问工具见上面的工具面一节。契约工具 `SubmitPlanItems` 对应[流程节点配置](流程节点配置.md)里的 `Output: Plan`。
