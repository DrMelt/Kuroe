# 模型接入

## 提供商与模型

提供商与模型的接入目录由 [ApiHub](https://github.com/DrMelt/ApiHub) 提供，保存在工作目录的 `catalog.json`，含明文凭据，不要提交。

- 提供商是模型的宿主，有名字、端点与凭据，`/provider add <名> <端点> <凭据>` 登记。
- 模型注册到提供商名下，`/model add <模型> <提供商>`。模型由名字引用。

节点引用的模型名、`Runtime:Model` 选中的模型都要能在目录里连通。命令见[命令参考](命令参考.md)的模型目录部分。

## 模型选择

模型选择有三处：

| 位置 | 含义 |
| --- | --- |
| `Runtime:Model` | 当前选用的模型，`/model` 维护 |
| 流程里的模型配置 | 执行节点按配置名引用的 `Models` 项 |
| 模型配置的 `Model` 字段 | 执行节点实际使用的模型名 |

执行节点解析模型时：用引用的模型配置的 `Model` 字段，未写时用 `Runtime:Model`；两者都缺时该节点阻塞并提示选择模型。未选择模型不影响启动，提交任务与发起对话时才会提示。

切换 `Runtime:Model` 会使旧上下文不再适用，会话按模型重建；凭据与端点变化不影响历史。

## 目录迁移

`/catalog export <文件>` 导出目录，凭据替换为占位符，可脱离本机分发；`/catalog import <文件>` 合并导入，文件参数相对工作目录解析。
