# 流程编译管线

## 阶段

| 阶段 | 输入 | 输出 | 属主 |
| --- | --- | --- | --- |
| 文本绑定 | 文件文本 | `FlowDocument` | `Kuroe.Flow.Json` |
| 描述构造 | `FlowDocument` 与类型目录 | 授权 `FlowDefinition` | `Kuroe.Flow.Compiler` |
| 库装配 | 授权流程、内置定义、文件定义 | 具体 `FlowDefinition` | `Kuroe.Flow.NodeLibrary` |
| 模型校验 | 具体 `FlowDefinition` | 诊断 | `Kuroe.Flow.Compiler` |
| 图编译 | 具体 `FlowDefinition` | `NodeGraph` | `Kuroe.Flow.Compiler` |
| 图校验 | `NodeGraph` | 诊断 | `Kuroe.Flow.Compiler` |
| 执行 | `INodeGraph` 与运行期输入 | 状态推进 | `Kuroe.Flow` |

`FlowDocument` 是唯一授权来源。`FlowService` 保存描述文档用于写回，保存 `CompiledDocument` 用于运行期查询与任务提交。写回直接从描述文档转成文本，不需要重建模型。

## 契约

| 契约 | 位置 | 职责 |
| --- | --- | --- |
| `FlowDocument` | `Kuroe.Flow.Compiler.Shared` | 描述文档：编译入口与文本格式契约共享的领域对象 |
| `FlowValue` | `Kuroe.Flow.Compiler.Shared` | 参数段的中立值 |
| `IFlowFormatReader` | `Kuroe.Flow.Json.Shared` | 文本到描述文档 |
| `IFlowFormatWriter` | `Kuroe.Flow.Json.Shared` | 描述文档到文本 |
| `IFlowDescriptionCompiler` | `Kuroe.Flow.Compiler.Shared` | 构造、展开、校验与图编译的统一入口 |
| `IFlowExpander` | `Kuroe.Flow.Shared` | 节点库合并、校验与展开 |
| `INodeTypeDescription` | `Kuroe.Flow.Shared` | 类型名、形状、字段表与描述到类型实例的转换 |
| `INodeTypeDescriptionRegistry` | `Kuroe.Flow.Shared` | 类型名到描述的唯一入口 |
| `IConsumedRevisionStore` | `Kuroe.Flow.Shared` | 按来源节点与来源端口记录已消费版本的读写契约 |
| `IFlowRuntimeCatalog` | `Kuroe.Flow.Compiler.Shared` | 按名取编译完成的流程 |
| `CompiledFlow` | `Kuroe.Flow.Compiler.Shared` | 校验通过的具体模型与执行视图 |

`CompiledFlow` 与 `CompiledDocument` 只由编译管线建立，运行期只消费，不现场编译。

## 规则属主

| 规则 | 属主 |
| --- | --- |
| JSON 语法、未知键、字段类型 | JSON 格式层 |
| 类型名已注册、参数未知字段与值形状、形状驱动的默认值与派生输出 | 描述构造层 |
| 描述文档的字段准入：定义与引用的字段互斥、容器与执行字段互斥、模型槽位归属 | 描述构造层 |
| 单节点不变量的组合入口 | `NodeSpec.Check` |
| 节点名、标签、保留名与 `@`、`/` | `NodeSpec.CheckIdentity` |
| 容器与执行节点的结构互斥 | `NodeSpec.CheckStructure` |
| From、In、Model、Models 与 Validate 的作用域限制 | `NodeSpec.CheckWiring` |
| 端口名唯一、端口类型落在注册值域、默认值、Context 输出上限 | `NodeSpec.CheckInterface` |
| 端口类型成对注册普通版与 Trigger 版，类型名唯一 | `PortTypes` |
| 输出校验参数与正则 | `OutputValidation.Check` |
| 输出校验判定 | `OutputValidation.Passes` |
| 模型名唯一、运行时模型与固定模型互斥、模型引用存在 | `FlowRules` |
| 模型槽位名与重复 | `NodeSpec.CheckModelSlots` |
| 输入侧就绪判定与 Trigger 抑制 | `NodeInputPlan` |
| 启动组因触发值为 false 被消耗时的已消费版本登记与通知，以及任务按是否还有活动节点收口 | `Kuroe.Flow` 的 `TaskRuntime` 与 `ConsumedRevisionStore` |
| 槽位声明与使用一致、绑定覆盖 | 节点库装配层 |
| From 组覆盖与组内唯一 | `FlowRules` 与节点库装配层 |
| 容器输出端口目标与 Context 来源 | 节点库装配层与 `FlowRules` |
| 类型专属规则 | `INodeType.Validate` |
| 自驱型节点的激活结果：版本推进、失败说明与返工重试 | `Kuroe.Flow` 的 `TaskRuntime`、`NodeRuntime` 与 `SelfDrivenRuntime` |
| 可达性、环、可见性与组间来源唯一 | `FlowRules` |
| 提交输入与开始端口一致 | `Kuroe.Flow` 的 `TaskActions` |
| 图构造的内部一致性 | `NodeGraph` |

同一处判定只在一个属主进行：描述构造层判文档字段能否写在该条目上，模型层判构造后的节点。两层对同一处误用给出同一文案，但输入不同，不互相替代。`NodeSpec.Check` 是模型层单节点不变量的唯一组合入口，流程校验、节点库校验与引用展开都经它或它所组合的规则判定。格式层不做模型判断，构造层只做字段准入与转换，库装配层不重复模型规则，图编译层不重复用户校验。

## 程序集边界

`Kuroe.Flow.Shared` 是充血领域层：图、执行与节点类型的接口、记录、枚举、值对象与领域对象自身的行为都在这里。节点不变量、产出校验判定与输入侧就绪判定属于领域行为，不抽到 Core。

`Kuroe.Flow.Compiler.Shared` 承载编译入口契约、编译结果契约与描述文档领域对象：`IFlowDescriptionCompiler`、`CompiledFlow`、`CompiledDocument`、`FlowDocument` 及其记录与 `FlowValue`。`Kuroe.Flow.Json.Shared` 承载文本格式契约：`IFlowFormatReader` 与 `IFlowFormatWriter`，并引用 `Kuroe.Flow.Compiler.Shared` 的描述文档。`Kuroe.Flow.Json` 承载 JSON 文本绑定：文件形状 DTO、源生成序列化选项、文本与 DTO 的读写、文件形状与描述文档的映射。

依赖方向为格式层到编译契约：`Kuroe.Flow.Compiler.Shared` 不引用承载格式，`Kuroe.Flow.Json.Shared` 引用 `Kuroe.Flow.Compiler.Shared`。

`Kuroe.Flow.Compiler` 承担编译期基础设施：类型描述注册表、描述构造、图编译与图校验。`Kuroe.Flow.NodeLibrary` 承担库装配。`Kuroe.Flow` 承担运行期基础设施：运行时节点、任务推进、已消费版本记录与执行生命周期；自驱型节点的公共运行期基类 `SelfDrivenRuntime` 在 `Runtime/Nodes`，供文件节点与命令节点复用。

外部状态与可替换基础设施经接口隔离。`INodeTypeDescriptionRegistry` 由 `NodeTypeDescriptionRegistry` 实现，`IConsumedRevisionStore` 由 `ConsumedRevisionStore` 实现，接口在 Shared，实现在 Core。纯领域计算留在对象上，不为单一实现增加接口。
