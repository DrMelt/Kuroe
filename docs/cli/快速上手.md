# 快速上手

从产物到完成一次 `run` 的最短路径。入口差异见[入口与分工](../usage/入口与分工.md)，产物与工作目录见[安装与运行](../usage/安装与运行.md)，完整命令见[命令行接口](命令行接口.md)。

## 环境与依赖

Kuroe.Cli 需要 .NET 10 运行时，不需要交互终端，也不读取 stdin。从 release 页面下载编译产物压缩包并解压。

## 启动

在产物目录执行：

```powershell
dotnet Kuroe.Cli.dll <命令> -d <工作目录>
```

`-d` 省略时用进程当前目录。`-h` 打印用法，参数错误以非零退出码结束。

## 注册模型

工作目录里还没有提供商与模型，先注册再接通：

```powershell
dotnet Kuroe.Cli.dll provider add openai https://api.openai.com/v1
dotnet Kuroe.Cli.dll model add gpt-4o openai
dotnet Kuroe.Cli.dll model use gpt-4o
```

`provider add` 的凭据参数省略时读环境变量 `KUROE_PROVIDER_KEY`。凭据写在命令行会进入 shell 历史，脚本与 CI 中优先用环境变量。

## 提交任务

```powershell
dotnet Kuroe.Cli.dll flow list
dotnet Kuroe.Cli.dll run --flow <流程> --input "目标=写一段百字以内的欢迎致辞"
```

`run` 提交任务并在本进程内驱动到完成、阻塞或取消，模型文本流式写 stdout，工具调用写 stderr。任务只存在于提交它的进程，进程退出后任务状态消失，任务目录保留。包含 `Input` 或 `Approval` 的流程不可用；需要等待输入或审批时用 Kuroe.Console。

## 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1 | 参数、装配或操作失败，含任务取消 |
| 3 | 任务阻塞 |
