# 快速开始

从安装产物到完成第一个任务。目标机需要 .NET 10 运行时，安装、产物与工作目录见[安装与运行](usage/安装与运行.md)。

## 准备流程

按[流程示例](reference/流程示例.md#单线撰写)把节点库写入 `.kuroe/nodes.json`，流程写入 `.kuroe/flows.json`，宿主开始输入写入 `.kuroe/hostStartInputs.json`，`.kuroe/` 不存在时先建立。这三个文件在 Console 启动时读取。

流程示例含「单线撰写」与「双稿比选」两个示例，本页使用前者；宿主开始输入表照抄示例即可，其中没有对应流程的表项不会被用到。

Console 运行中改动节点库或流程，从「流程」菜单的「导入流程」分别导入 `.kuroe/nodes.json` 与 `.kuroe/flows.json`，先节点库后流程；重启 Console 也会重新读取。宿主开始输入表只在启动时读取，改动后必须重启。

## 启动

在产物目录执行：

```powershell
dotnet Kuroe.Console.dll -d <工作目录>
```

`-d` 省略时用启动进程的当前目录。

## 注册模型

主菜单进入「模型与提供商」，依次：

1. 「添加提供商」，填写名称、端点与凭据
2. 「注册模型」，选择提供商后填写本地模型名与提供商模型名，后者留空时用前者
3. 「选择模型」，选中刚注册的模型

提供商与模型的含义见[模型接入](usage/模型接入.md)。

## 提交任务

1. 主菜单进入「任务」，选「提交任务」
2. 选「单线撰写」，填写「目标」与「风格」并确认，`TASK_WORK_PATH` 与 `MODEL_NAME` 由宿主给值，以只读行展示
3. 在任务列表选中任务，查看概览、执行详情、节点树与过程记录

## 结果

任务在列表显示已完成时，定稿已写入本次任务目录的 `单线定稿.md`，任务目录见[任务与执行](usage/任务与执行.md)。
