# 快速开始

从环境准备到完成第一个任务。产物与工作目录见[安装与运行](usage/安装与运行.md)。

## 环境

目标机需要 .NET 10 运行时。从 release 页面下载产物压缩包，解压到任意目录。

## 启动

在产物目录执行：

```powershell
dotnet Kuroe.Console.dll -d <工作目录>
```

`-d` 省略时用启动进程的当前目录。

## 注册模型

主菜单进入「模型与提供商」，依次：

1. 「添加提供商」，填写名称、端点与凭据
2. 「注册模型」，选择提供商后填写本地模型名与提供商模型名，后者留空时用前者
3. 「选择模型」，选中刚注册的模型

## 第一个任务

流程库初始为空，先把下面这条流程写入工作目录的 `.kuroe/flows.json`，目录不存在时先建立。节点库写在 `.kuroe/nodes.json`，本示例不需要：

```json
{
  "Flows": [
    {
      "Name": "第一个任务",
      "Start": { "Outputs": [
        { "Name": "目标", "Type": "Text", "Mode": "Constant" },
        { "Name": "MODEL_NAME", "Type": "Text", "Mode": "Constant" }
      ] },
      "HostStartInputs": { "MODEL_NAME": "MODEL" },
      "Root": {
        "Name": "撰写",
        "Kind": "Llm",
        "Emission": "Once",
        "Bindings": { "目标": "Start@目标", "MODEL_NAME": "Start@MODEL_NAME" },
        "Prompt": "完成目标，交回结果。",
        "Inputs": [{ "Name": "目标", "Type": "Text", "Mode": "Constant", "Role": "Content" }],
        "Outputs": [{ "Name": "结果", "Type": "Text", "Mode": "Constant" }]
      }
    }
  ]
}
```

这条流程在提交时填写「目标」，模型由 Kuroe 在任务启动时给出，「撰写」节点执行一次并把结果交回常量端口。字段与节点写法见[流程定义](reference/流程定义.md)与[节点](reference/nodes/index.md)。

Console 已在运行时，从「流程」菜单的「导入流程」加载。提交任务：

1. 主菜单进入「任务」，选「+ 提交任务」
2. 选流程后填写「目标」并确认
3. 在任务列表选中任务，查看概览、执行详情、节点树与过程记录

流程改动后重新导入或重启 Console 生效。
