# 架构测试

项目引用、跨层类型与执行写入口的约束由 `Tests/Architecture` 下的测试固定。新增引用、跨层类型或执行写入口时先补齐或调整对应断言。

## 覆盖范围

| 文件 | 覆盖 |
| --- | --- |
| `RepositoryStructureTests` | 仓库结构、`InternalsVisibleTo` 目标、图命名空间归属项目、共享测试工程引用、编译集成测试与宿主分离、禁用词汇的全局残留 |
| `KernelAreaTests` | Kernel 只引用 Kernel、Kernel 源码不出现图与节点词汇、Kernel 不出现具体流程记录、输入项目边界、中性共享层不使用图命名空间 |
| `KernelControlTests` | 控制共享契约、流程运行期、执行索引与执行网关、流程模板目录、恢复按身份解析 |
| `KernelExecutionTests` | 执行契约与共享项目、执行状态机归属、派发器职责、执行记录来源 |
| `KernelTaskTests` | 任务域与任务注册表、任务快照装配归属、执行记录来源标识、任务动作与执行归属、工作树状态改动面 |
| `PresentationBoundaryTests` | 表现共享与任务表现的项目归属 |
| `RecordPersistenceTests` | 图记录边界、持久化项目引用边界、任务持久化不出现流程模型、记录种类常量与编解码器随实现存放 |
| `FlowAreaTests` | 编译契约的引用边界、节点与图各自持有实现、图共享层的引用边界、图执行接口命名、流程实现按职责拆分端口、图状态保存执行上下文 |
| `DocumentBoundaryTests` | 描述文档不引用其他工程、描述文档 JSON 层只引用描述文档与契约层、描述文档不含流程实现 |
| `NodeRunnerTests` | 节点引用自身运行器实现、运行器不引用节点与图、运行期能力中性、运行器共享契约无项目引用 |
| `HostAndToolBoundaryTests` | 宿主与代码流程源码不导入图命名空间、宿主不引用图运行期与图共享层、文件访问共享项不依赖同模块核心 |
| `AssistantBoundaryTests` | 助手宿主只依赖代码流程、对话宿主与代码流程分区 |
| `MafBoundaryTests` | MAF 与 Kernel 契约的引用关系、MAF 类型不进入 Kernel 与宿主、MAF 运行期不引用流程区域、文档装配只引用流程共享契约 |

## 命名空间约束

命名空间根与项目名一致，`Kuroe.Runner.Shared` 的根为 `Kuroe.Runner`。图命名空间的分段固定，归属由 `RepositoryStructureTests` 的 `Graph_namespaces_follow_their_owning_projects` 检查。
