# Kuroe.Tool.Json

工具文件层：文件里配置的工具定义与运行期创建函数、工具文件形状注册表与统一装载。

## 职责

- 工具文件形状注册表：文件名到实现的唯一入口，注册必须显式，注册在装配前完成，之后只读，同名处理见[同名覆盖与重名](../../mechanism/overrides.md)。
- 统一装载：按注册表读取全部工具文件，合并结果并校验跨文件的路径重复。
- 文件里配置的工具：定义、供列出配置的形态与按执行创建载体的函数。
- 工具文件层错误构造。

## 边界外

- 不含工具载体与调用上下文：在 Kuroe.Tool。
- 不含具体文件格式：命令工具文件在 Kuroe.Tool.Implementation.Command.Json。
- 不含流程、图与节点。

## 依赖

- Kuroe.Tool、Kuroe.Shared。
