# Kuroe.Tool.FileAccess.Shared

文件访问契约：根目录内的路径解析与越界拒绝、目录列举、按行号读取、文本搜索与批量替换，以及行号范围、换行风格与查找模式的形状。

## 职责

- 文件访问接口：路径解析与越界拒绝、列目录、按行号范围读取。
- 文本搜索：展开路径范围，按后缀与查找模式筛选，匹配累计到预算或次数上限后停止。
- 批量替换：展开路径范围，按后缀筛选文本文件，在每个文件内替换全部不重叠匹配。
- 查找模式：字面与正则两种语义，统计匹配并按模板展开替换文本。
- 行号范围：起始行与结束行，缺省值由调用方给定。
- 换行风格：LF、CRLF 与 CR 的归一、识别与转换。
- 读取输出上限：正文总字符与单行行长。
- 结果形状：搜索命中、扫描计数、替换处数与失败原因。

## 边界外

- 不含实现：在 Kuroe.Tool.FileAccess。
- 不含工具载体与调用上下文。
- 不含工作区文件系统：在 Kuroe.Files。
