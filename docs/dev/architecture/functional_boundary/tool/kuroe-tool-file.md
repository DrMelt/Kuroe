# Kuroe.Tool.File

file 工具组：读取、写入、搜索、批量替换、列举、信息查询、移动与删除，路径解析后必须落回工作区内。

## 职责

- 工具源：装配期提供定义，运行期按执行绑定创建本轮可用的文件工具。
- 读取：按行号范围读取文本文件。
- 写入：把文本覆盖写入文件，父目录缺失时自动创建。
- 搜索：按字面文本或正则表达式搜索文件内容，报告计数与匹配行。
- 批量替换：在多个文本文件中替换匹配，逐文件保留编码、BOM 与换行风格。
- 列举与信息：列出目录条目，取文件的文件系统信息。
- 移动与删除：目标已存在时拒绝移动，非空目录删除需要显式声明，路径基准目录本身拒绝删除。
- 输出上限与写回编码解析由文件访问工具面共用。

## 边界外

- 不含文件访问契约与文本处理：在 Kuroe.Tool.FileAccess.Shared 与 Kuroe.Tool.FileAccess。
- 不含工作区文件系统实现：在 Kuroe.Files。
- 不含工具载体框架与命令工具。
