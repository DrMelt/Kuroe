# Kuroe.Tool.Contract

执行契约工具：把端口交回、无法完成上报与契约状态查询提供给模型，按执行建立载体。

## 职责

- 交回通道：声明了需交回输出端口的执行节点按命名端口交回产出。
- 上报通道：上报本轮无法完成并给出原因。
- 状态查询：查看本轮执行契约状态与尚缺的端口。
- 端口形状：按当前执行的端口声明给出每个端口的字符串或对象形态，schema 与解析共用同一套字段名。
- 回执文本：本轮还需交回的产出，各契约入口共用一份措辞。
- 工具定义与工具源：引擎按路径放行，按执行创建本轮可用的载体。

## 边界外

- 不含执行单元与契约规则：在 Kuroe.Execution.Shared。
- 不含工具载体框架：在 Kuroe.Tool。
- 不含流程控制与图。
