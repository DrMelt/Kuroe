# Kuroe.Tool

工具载体与工具面：函数定义、调用上下文、工具源、调用记录、路径与路径变量契约，以及按执行组合工具路径的规则。模型可调用的全部能力都由这里声明。

## 职责

- 工具载体：按执行给出函数声明与调用体，声明是模型可调用的全部能力。
- 工具源：装配期提供函数定义，运行期按执行上下文创建本轮可用的载体，只有落在本轮工具面内的条目才创建。
- 函数定义：路径、说明、参数、互斥参数组与路径变量，不含调用体与运行期状态。
- 调用上下文：端口访问、执行请求入口、轮次与上限、本轮工具面、工具变量到端口的映射与工作区根。
- 调用记录与实参：参数文本由实参生成，实参既接受模型给的 JSON 也接受已解析的同义形式。
- 路径与路径变量契约：工具路径与变量名的装载期约束，流程编译按它校验节点映射。
- 工具路径组合：执行白名单、按需附上的端口交回能力，以及所有执行共有的上报与查看通道。
- 结果交回：成功取返回文本，失败合并错误说明交给模型。
- 调用错误：拒绝与失败的错误码与构造，渲染为模型文本，不进入宿主错误链路。
- 布尔参数与列表参数在交给模型时的形状声明。

## 边界外

- 不含具体工具实现：在 Kuroe.Tool.* 的各工具组。
- 不含工具文件读写与注册：在 Kuroe.Tool.Json。
- 不含流程实现、图与节点。
- 不含模型调用：在 Kuroe.Runner.Llm。
