# Kuroe.Assistant

内置助手：独立的会话任务域、代码定义的对话流程、会话目录与工具面。会话存档与用户任务分开，共用执行索引、流程运行期与执行单元。

## 职责

- 装配入口：在核心装配之上注册助手，工具去重与核心共用同一工具集。
- 会话任务域：独立的注册表、存档目录、写盘协调、租约与恢复服务。
- 对话流程：代码定义，状态由对话流程自身维护，不经过节点图；等待输入与每轮执行。
- 会话目录：建立、选择、改名与删除会话，给出只读摘要；模型与语言在会话建立时固定。
- 会话轮次：同一会话同一时刻只允许一轮，轮次结束给出通知。
- 能力模式：决定每轮执行可用的工具与恒定指令。
- 会话历史读取：基础历史取最后一次可读的恢复数据，其后的执行作为尾部返回。
- 工具面查询源：内置对话各模式白名单与配置工具的只读呈现。

## 边界外

- 不含执行索引、流程运行期与执行单元。
- 不含图流程与图命名空间。
- 不含输入实现与工具实现本身。
- 不含宿主装配与入口。
