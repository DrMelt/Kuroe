# Kuroe.Kernel.Tasks.Records.Shared

任务存档记录的共享形状：完整任务存档、任务身份、任务级过程记录、锁定的流程记录，以及流程定义片段与状态片段的编解码端口。中央序列化只按这层形状读写，不按流程种类分支。

## 职责

- 任务存档：身份、保存时刻、生命周期、完成事实、过程记录、流程记录与执行记录。
- 任务身份：跨进程唯一的持久键与会话归属。
- 任务级过程记录。
- 流程记录：流程身份、流程定义记录与流程状态记录，两类记录由流程实现提供。
- 流程片段：定义片段与状态片段，内容由流程实现写出与读取。
- 编解码端口：按流程身份认领，把两类记录与存档片段互相转换，错误经返回值报告。

## 边界外

- 不含任务域与捕获时机。
- 不含具体流程记录与种类常量：由 flow、codeflow 与 maf 各自持有。
- 不含文件存储与文档组装。
- 不依赖图、流程控制与持久化实现。
