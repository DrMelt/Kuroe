# Kuroe.Tasks.Shared

任务与流程的中性值模型：任务标识与状态、流程身份、流程步骤路径、端口文本、等待步骤、开始输入与标题推导。不依赖执行实现、图与流程控制。

## 职责

- 任务标识与任务键生成：跨进程唯一的键，键的分配可替换。
- 任务状态：控制状态与整体状态的汇总口径、判定与展示名。
- 任务标题推导：未给出标题时取第一个开始输入的首行，过长时截断。
- 流程身份：流程名、流程种类与实现标识；提交按流程名解析，恢复按种类与实现标识解析。
- 流程步骤路径：从根到步骤的标签序列，流程控制与宿主只使用它。
- 端口文本：开始端口文本与已装配端口文本的读取面。
- 等待步骤：路径、等待种类与给外部的提问。
- 开始输入：提交任务时给出的端口名与文本。
- 错误码与错误构造：流程与流程装配的可操作错误。

## 边界外

- 不含任务聚合与注册表：任务域在 Kuroe.Tasks.Runtime。
- 不含执行形状：执行身份与状态在 Kuroe.Execution.Shared。
- 不含流程控制与流程实现，不含图与节点词汇。
