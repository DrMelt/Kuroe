# Kuroe.Kernel.Input.Shared

输入通道契约：等待外部输入的步骤登记、输入交付与交付错误。只声明登记与交付，不持有任务状态。

## 职责

- 等待登记：按任务与流程步骤路径登记等待步骤，重复登记同一步骤时替换原登记。
- 登记撤销：步骤交付输入或任务清理时撤销。
- 宿主交付面：读取任务此刻等待的步骤、向等待步骤交付一次输入并清空任务登记。
- 变更通知：登记变化时通知宿主刷新任务快照。
- 交付错误：步骤不在等待输入或没有登记。

## 边界外

- 不含任务状态与快照：等待步骤经任务只读视图读取，见 Kuroe.Kernel.Tasks.Presentation.Shared。
- 不含流程推进：交付只完成等待，推进由流程控制承担。
- 不含实现：进程内登记实现在 Kuroe.Kernel.Input.Runtime。
