# Kuroe.Kernel.Presentation.Shared

流程表现的共享视图形状：流程模板、步骤、分组、端口、开始端口与执行，以及状态与时间的展示名和过程记录文本切分。宿主只读取这些形状，不读取流程实现内部状态。

## 职责

- 流程模板视图：开始端口、执行步骤与分组。
- 步骤视图：路径、标签、种类、状态、输入、输出与执行列表。
- 分组视图与步骤状态取值。
- 端口视图：名称、种类、文本与触发位；开始端口另带输入来源与宿主绑定。
- 执行视图：标识、状态、过程与输出端口。
- 展示文本：状态与时间的统一展示名，过程记录按逻辑行切分。

## 边界外

- 不含任务快照与等待步骤：在 Kuroe.Kernel.Tasks.Presentation.Shared。
- 不含视图装配：由流程实现捕获流程视图，由任务域装配任务快照。
- 不含图与节点结构，不含流程控制。
