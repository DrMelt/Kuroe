# Kuroe.Kernel.Execution

执行单元机制实现：执行状态机、执行实例建立与恢复、运行器接线与派发调度。只消费执行请求与装配结果，不读取节点、图与任务。

## 职责

- 执行状态机：排队、运行、收口、中断与终态取值，状态迁移只在本层完成，写方法不对外。
- 执行实例：过程记录附加、用量累计、恢复数据记录、本轮契约状态与产出的持有。
- 运行包裹：建立请求入口与运行器，运行一轮并收口；恢复时按存档数据重建。
- 派发器：按并发额度排队运行，执行收口回调，支持中断排队与在跑的执行。
- 控制面：按装配结果建立、恢复、准备恢复、运行收口、中断与退出收口。
- 状态快照：对外给出只读执行快照。

## 边界外

- 不含执行形状。
- 不含任务与流程：任务域与流程控制不调用本层状态迁移。
- 不依赖节点、图与持久化；执行记录由任务域捕获。
