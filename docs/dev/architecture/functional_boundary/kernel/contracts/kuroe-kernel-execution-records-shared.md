# Kuroe.Kernel.Execution.Records.Shared

执行存档记录的共享形状：一次执行持久化的状态、输入、用量、恢复数据与契约，以及把执行快照捕获为记录的统一入口。纯记录层，不引用任务与流程。

## 职责

- 执行记录：状态、起止时刻、产出、失败原因与恢复来源。
- 输入记录：输入端口的取值与不透明来源标识。
- 用量记录：模型 token 累计。
- 恢复记录：由执行实现自己解释的恢复负载。
- 契约记录：本轮交回的端口与无法完成原因。
- 捕获：把中性执行快照整理为上述记录。

## 边界外

- 不含执行实现。
- 不含任务记录与流程记录，不做编解码。
- 不依赖任务、流程与持久化。
