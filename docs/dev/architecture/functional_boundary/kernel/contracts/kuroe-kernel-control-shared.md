# Kuroe.Kernel.Control.Shared

流程控制的契约层：控制实例与控制工厂、执行网关、任务能力面、流程提交与恢复、流程表现、流程记录来源与流程模板目录。流程实现只实现这里的接口，任务域只按这些接口驱动控制。

## 职责

- 控制实例：启动、暂停、恢复、终止与收口；按步骤重跑由可选面单独提供。
- 控制工厂：按任务建立控制实例。
- 执行网关：流程控制访问执行单元的唯一端口，覆盖建立、查找、恢复、运行、中断与拒绝执行。
- 执行索引面：按执行号查找执行与归属任务。
- 任务能力面：控制实例读写任务身份、控制状态、过程记录与执行集合，并执行状态迁移。
- 任务只读面：流程表现与任务快照读取任务，不持有状态改动能力。
- 流程提交与恢复：校验开始输入并给出初始状态，从存档重建流程状态。
- 流程身份判定与流程实现查找。
- 流程表现与流程记录捕获：只提供流程视图，等待步骤由任务视图提供。
- 流程模板：只读目录与来源登记，宿主浏览流程与生成提交表单。
- 任务快照装配与任务动作端口：宿主经此提交与操作任务。
- 流程运行期驱动：启动、暂停、恢复、重新执行与终止任务。

## 边界外

- 不含控制实现。
- 不含任务聚合与任务注册表。
- 不含具体流程种类与流程记录，不依赖图与节点。
