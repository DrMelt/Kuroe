# Kuroe.Flow.Compilation.Shared

流程描述的共享模型与校验规则：流程、节点定义与引用、连接、参数段取值、节点类型描述与校验契约，以及统一报错口径。编译管道只按这些形状工作。

## 职责

- 流程描述：流程名、开始端口与装配树。
- 节点描述：定义节点、引用节点与容器的公共字段与各自差异。
- 连接描述：目标输入端口、来源引用与触发条件，条件未写时按正向。
- 参数段：字段声明、取值形态与读侧，形状不符报错，缺失取安全默认。
- 节点类型描述注册表与校验契约：类型名到描述的唯一入口，类型可选地校验落地后的不变量。
- 节点规则：标识、结构、接线与端口绑定，违规经作用域拼成统一错误文本。
- 编译入口与库展开：构造、展开、校验与图编译的固定顺序，库装配把授权流程与节点库定义展开为具体流程。
- 描述值：承载参数段与原始键值，不依赖承载格式。

## 边界外

- 不含编译实现：文档构造、模型校验与图编译在 Kuroe.Flow.Compilation。
- 不含图运行期与流程控制。
- 不含文件格式：在 Kuroe.Flow.Json。
