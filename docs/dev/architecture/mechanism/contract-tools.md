# 执行契约工具

执行契约工具把端口交回、无法完成上报与状态查询交给模型，供任何声明了输出端口的流程共用。本文说明它与流程控制、执行单元之间的约定。

## 依赖范围

执行契约工具只依赖 `IExecutionRequestEntry`、`ExecutionRequest` 与 `ExecutionContractRules`。端口交回、无法完成上报与状态读取不引用具体流程控制，不强制转换为图控制。

流程实现只要在执行请求的 `OutputPorts` 声明输出端口，就能使用同一套契约工具。

## 缺口计算

状态读取按执行请求的端口与执行记录的契约计算缺口。轮次与上限由流程控制注入执行器参数，不从执行请求读取。

## 载体与路径

契约工具的载体按执行建立，载体只知道本次对应的执行。工具路径由 `ExecutionToolPaths` 给出，运行器与宿主工具装配共用同一份组合规则：声明的白名单、按需交回输出端口附上的交回能力，以及所有执行共有的上报与查看通道。
