# 流程语义解释

流程描述到流程实现之间的一次语言解释：描述构造与展开由流程描述编译完成，语言解析与语言规则由流程语义完成，图流程只把语义结果映射成静态视图，MAF 只做目标适配与可表达性判定。

## 四层分界

| 层面 | 内容 | 归属 |
| --- | --- | --- |
| 语言合法性 | 端口声明、绑定目标、组覆盖、触发来源、类型一致、可见性、可达性、常量依赖环与引用环 | 流程描述 |
| 语言可解析性 | 引用存在、作用域唯一、来源终点、静态来源链、容器映射 | 流程描述 |
| 目标适配 | 选择来源信息、转成目标形状、决定适配失败 | 流程实现 |
| 目标表达能力 | 目标模型承载的结构、端口与推进方式 | 流程实现 |

流程描述不感知目标实现。图流程与 MAF 都消费同一份语义结果，不重新判定语言规则。

## 阶段顺序

语言解析先于语言规则。解析失败时该流程只给出解析诊断，不再执行语言规则；跨流程诊断仍一次聚合。图视图不变量错误由图视图构造以异常暴露，不作为编译诊断。

## 消费约束

- 图流程只消费语义结果，不重新解析标签作用域、来源终点与静态来源链，只把来源映射成接线绑定并构造静态视图。
- MAF 只消费语义结果，不重新解析标签作用域、来源终点与静态来源链。
- MAF 只判定目标模型能否表达已合法且可解析的流程。
- 目标适配可以决定使用哪些解析结果，不能改变语言层的是非判断。
- 语义结果只承载流程定义与语言解析结果，不承载目标步骤、目标连接与运行期取值。

## 诊断归属

| 诊断 | 产生方 | 含义 |
| --- | --- | --- |
| 语言规则错误 | 流程描述语义层 | 模型不合法，含可达性、常量依赖环与引用环 |
| 语言解析失败 | 流程描述语义层 | 模型合法但引用无法解析 |
| 目标不可表达 | MAF | 模型合法且可解析，目标模型没有对应形状 |

语义诊断带节点定位。目标诊断带流程定位，并可引用节点定位，不重新构造。图视图不变量错误由图视图构造以异常暴露。

## 扩展点

- 节点类型通过类型描述注册表进入语言模型，不参与语义解析实现。
- 目标实现通过执行器能力扩展点登记节点类型与执行器绑定，不影响语言解析。
- 宿主装配负责把语义实现、流程描述编译与目标装配组合为可提交来源。
