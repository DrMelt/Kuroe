# 存档与持久化

任务存档是任务级权威记录，写盘由协调服务在后台合并完成，流程片段由各流程实现解释。用户可见的任务数据与恢复操作见[任务与执行](../../../user/usage/任务与执行.md)。

## 存档文件与写盘

`.kuroe_tasks/.records/` 下每个任务一个存档文件与一个租约文件。存档保存写入时刻、任务级记录、全部执行记录、节点状态与端口发布历史，在任务提交、执行启动与收口、等待输入、生命周期动作、完成与退出时更新。

状态变化先标记待写，由后台合并写盘，交互动作不等写盘；任务提交与终止在返回或释放租约前等待存档落盘，保证其他进程立即看到该状态。

存档格式版本为 16，读取只接受版本 16，其他版本按版本不符拒绝。

## 存档内容

流程记录保存流程名、流程种类、实现标识与流程实现自己的定义与状态片段。端口发布历史作为顶层字段保存，节点状态只记录当前活动发布版本。

执行契约随执行记录保存，恢复执行继承来源执行已交回的端口与无法完成原因。每次执行收口把节点类型给出的恢复数据写入执行记录，成功、失败、中断、重新执行、上游产出变化、任务完成与终止都不删除，作为执行历史保留。执行过程记录只在运行中可见，不写入存档。

Llm 的恢复数据使用 Microsoft Agent Framework 会话快照。

## 编解码边界

任务存档文档只保存通用任务字段、执行记录、流程身份与两段流程片段。流程片段由 `IFlowRecordCodec` 解释，中央序列化不按流程种类分支。片段读写约定：读取拒绝未定义字段，写出省略空字段。

执行记录由任务域从执行快照捕获。流程实现只提供 `FlowRecord`，包含流程定义与流程状态，不捕获执行记录。

图流程、代码流程与 MAF 流程各自提供记录项目与编解码项目，注册到宿主时与 `FlowProvider` 并列；需要进入流程目录的实现另注册 `IFlowTemplateSource`。编解码端口 `IFlowRecordCodec` 与 `FlowRecordData` 位于 `Kuroe.Kernel.Tasks.Records.Shared`。新增流程实现提供自己的定义记录、状态记录、种类常量与编解码器即可，不修改中央序列化项目。

编解码错误经返回值报告，不穿透 `FormatException`。

## 助手会话存档

助手会话的存档与租约位于 `.kuroe_assistant/records/`，使用独立的任务注册表、存档源、写盘协调、租约与恢复服务，执行索引、流程运行期与执行运行期与用户任务域共用。会话启动时先恢复用户任务，再恢复助手会话；退出时先中断全部任务与执行一次，再分别写出两者的存档、释放租约并丢弃任务域。

会话历史来自执行恢复数据。最后一次可读的恢复数据提供基础历史，其后的执行按执行记录补齐输入与状态。执行记录不保存展示文本，恢复负载不含展示段。历史读取由 Llm 执行单元提供，展示层决定显示角色、内容种类、截断与省略。
