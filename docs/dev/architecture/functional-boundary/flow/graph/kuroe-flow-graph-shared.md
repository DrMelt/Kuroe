# Kuroe.Flow.Graph.Shared

图流程的静态图与运行期形状：静态执行视图、接线绑定、运行期节点与端口状态、就绪判定、图执行输入与执行契约、节点记录与执行步骤标识。

## 职责

- 静态图：流程图、节点图、可执行节点、容器节点、输入方案与接线绑定。
- 图节点能力：执行器绑定、输出投影与运行期工厂的映射。

- 运行期节点：输入取值、输出发布与多版本消费、上下文取值、节点状态与阻塞。
- 就绪判定：按输入进度、输出发布与触发位判断节点能否执行，调度种子决定启动顺序。
- 图执行输入与执行契约：一次执行进入图时的输入形状与对外契约。
- 执行快照与步骤路径：节点执行步骤标识、执行快照与节点声明解析。
- 节点记录：节点状态、端口发布、输入进度与上下文来源的可持久化形状。
- 宿主开始端口绑定：开始端口取值与宿主输入的接口。

## 边界外

- 不含描述模型与端口词汇。
- 不含描述构造、库展开与图编译。
- 不含图运行期调度与流程控制。
- 不含具体节点类型与运行器实现。
- 不含持久化编解码与文件格式。
