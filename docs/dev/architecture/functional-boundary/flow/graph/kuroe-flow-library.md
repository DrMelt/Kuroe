# Kuroe.Flow.Library

流程库：把节点库与流程文件读成流程描述集合并编译为运行期流程，提供导入、只读查询与流程快照。

## 职责

- 流程库：流程描述是授权来源，编译结果是运行期来源，逐条流程隔离编译失败。状态由库独占，导入是唯一写入口。
- 流程文档：给出当前流程描述，供共同装配入口交给其他流程实现。
- 只读查询：实现流程目录契约，给出展开定义与编译结果两种投影。
- 流程快照：按当前文档捕获存档文本，把快照文本重建为可运行流程，重建不依赖库状态。
- 导入：从文件导入节点库或流程，给出导入条目与逐条说明。
- 流程编译接线：把描述编译器与图编译器组合为流程编译入口。

## 边界外

- 不含文件存取。
- 不含宿主装配、宿主开始输入与任务工作目录。
- 不含图运行期与图控制实现。
- 不含描述模型与描述编译。
- 不含节点类型与执行器实现。
