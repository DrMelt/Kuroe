# Kuroe.Maf.Compilation

MAF 文档装配实现：把语言解析完成的流程投影成 MAF 流程定义，保留目标结构诊断，并提供按流程名取定义的来源。

## 职责

- 文档装配：流程描述交给流程描述编译与语言解析，逐流程投影，错误一次给全。
- 目标适配：按语言解析结果取上游来源、静态来源、启动组与触发条件，转成步骤输入计划。
- 流程投影：把流程定义的开始端口、步骤、步骤输入、输出计划与连接转成 MAF 流程定义。
- 结构诊断：检查来源终点缺失、步骤标识重复、输出映射缺失、入口可达性与环。
- 文档来源：装配一次后按流程名提供定义。

## 边界外

- 不含装配契约。
- 不含描述构造、库展开与语言规则校验。
- 不含作用域解析、来源解析与语言诊断。
- 不含图静态视图与图编译。
- 不含节点执行器实现。
- 不含流程定义与运行期。
