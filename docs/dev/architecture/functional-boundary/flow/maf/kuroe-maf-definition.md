# Kuroe.Maf.Definition

MAF 流程定义：流程名、开始端口、步骤与连接，以及步骤的执行装配声明。定义由宿主以代码给出或由流程描述装配，不写回工作目录。

## 职责

- 流程定义：流程名、开始端口、步骤、连接与说明。
- 步骤：标识、标签、输出端口与输出计划、模型端口、执行装配工厂。
- 输入计划：端口种类、执行角色、启动组、触发条件、来源、取值与 Context 内容。
- 输出计划：端口种类、触发标记、交回要求与 Context 透传内容。
- 开始端口：取值种类、模式、默认值与提交要求。
- 入口集合：全部无入边步骤。
- 定义校验：标识、输出端口、连接端点、入口存在、可达性与开始端口声明，模型开始端口按步骤的模型端口要求。
- 步骤标识：同时作为执行步骤标识与流程步骤路径，提交时与装配结果校验一致。
- 执行装配声明：执行运行器工厂与按本次执行上下文构造参数的入口。
- 定义来源与查找：宿主提供可供提交的 MAF 流程，按流程名查找。

## 边界外

- 不含运行期。
- 不含存档记录与编解码。
- 不依赖图、节点、流程控制与存储。
