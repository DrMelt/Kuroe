# Kuroe.Host.Platform

宿主共享契约：路径变量与占位符、工作区路径边界、变量映射规则、模型目录与生效配置的只读视图、设置与目录改动结果、启动信息与错误码，不依赖流程、节点、工具与执行。

## 职责

- 路径变量：占位符写法、装载期校验与运行期解析，解析结果落在工作区内，根变量作为相对路径基准。
- 工作区路径边界：路径规范化、包含判定与同一路径判定，按平台文件系统规则比较。
- 变量映射规则：变量名合法、端口已声明且承载文本、变量集合与占位符一一对应。
- 模型目录只读视图：一次读取给出来源、模型清单与当前选中模型，凭据只报是否已设置。
- 生效配置视图：设置项按节声明、取值文本与用户层是否设置。
- 配置改动影响：是否即时生效、是否影响上下文与既有对话。
- 目录合并结果：导入来源、逐条说明与凭据仍为占位符的来源。
- 模型改动结果：选择与注销的结果、改动影响与失败原因。
- 启动信息：装配完成时交给宿主。
- 错误码：设置、工具、工作目录、命令行、任务目录与开始输入的常量错误码。

## 边界外

- 不含目录与配置的实现。
- 不含流程、节点、工具与执行。
- 不依赖任何项目。
