# Kuroe.Host.FlowIntegration.Maf

MAF 流程装配入口：由宿主在核心装配完成后调用，注册 MAF 流程实现、存档编解码与流程模板。

## 职责

- 装配入口：注册流程实现、存档编解码与模板来源，宿主一次调用即可提交 MAF 流程。
- 按定义来源登记可供提交的 MAF 流程。
- 执行器能力登记：把节点类型绑定到节点项目给出的执行器，供文档装配使用。
- 按流程描述装配：接受完整流程描述与共享描述编译，逐流程装配，建立 MAF 流程来源。
- 编译诊断：失败流程不注册，保留流程名与原因，供共同装配入口合并启动诊断。
- 模型来源：宿主给出当前模型来源时，提交阶段把当前模型补入模型开始端口，模型端口在模板中按宿主给值呈现。
- 执行运行器：使用图流程装配结果给出的执行运行器，与图流程共用同一组配置。

## 边界外

- 不含流程定义。
- 不含描述编译、语言解析与目标适配。
- 不含运行期与检查点。
- 不含编解码实现。
- 不含核心装配、图流程与入口项目。
