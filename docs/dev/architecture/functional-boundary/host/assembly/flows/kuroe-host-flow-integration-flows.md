# Kuroe.Host.FlowIntegration.Flows

流程实现的共同装配入口：在核心装配之后建立图流程，交给 MAF 装配同一份流程描述，登记两个实现的流程变体并合并启动诊断。Console 与 CLI 都经此入口装配流程。

## 职责

- 共同装配：建立图流程装配结果，复用其中的流程文档、描述编译器与执行运行器。
- 同一文档装配：图流程编译全部流程，MAF 逐流程装配同一份文档，两个实现互不排除。
- 变体登记：图流程与 MAF 各自登记自己的流程模板，同一流程名可以有两个变体。
- 可用性合并：按流程名比较两个实现的结果，两个都失败时给出两份原因，单个失败只影响对应变体。
- 执行器绑定：把节点类型绑定到图流程提供的执行运行器，供 MAF 文档装配使用。
- 模型来源：把宿主当前模型交给 MAF 提交与模板。

## 边界外

- 不含流程推进与控制。
- 不含描述编译、语言解析与 MAF 目标适配。
- 不含节点实现与执行运行器实现。
- 不含入口命令与界面。
