# Kuroe.Host.Ability.Tool.Implementation.KuroeInfo

KuroeInfo 工具组：模型目录、流程模板、生效配置、任务与执行、工具面的状态查询。全部只读，不产生状态改动，凭据不交给模型。

## 职责

- 模型目录查询：给出可用模型与选择状态。
- 流程模板查询：给出可提交的流程、引擎与开始端口。
- 配置查询：给出生效配置。
- 任务与执行查询：按任务快照给出任务状态、执行与过程记录。
- 工具面查询：列出内置对话各模式放行的路径前缀与配置的命令工具及其调用名与路径。

## 边界外

- 不含任务域与流程控制：查询只读取快照与目录。
- 不含工具载体框架。
- 不含宿主装配与入口。
