# Kuroe.FlowDescription.Compilation.Shared

共享描述编译的对外契约：编译入口、库装配入口、节点类型描述的扩展契约与参数读取。

## 职责

- 编译入口：把流程描述编译为语言合法且引用可解析的流程语义结果。
- 语义结果：流程定义与语言解析结果一并给出，跨流程诊断一次聚合。
- 库装配：校验文件节点库并逐流程展开。
- 节点类型契约：类型名、静态形状、字段表与描述到类型实例的转换。
- 类型注册表：类型名到描述的唯一入口。
- 参数读取：按字段名取本轮取值，字段声明描述取值形态。

## 边界外

- 不含描述形态。
- 不含静态模型、端口词汇与语言规则。
- 不含编译实现、语言解析实现与目标适配。
- 不含文件格式。
