# Kuroe.FlowDescription.Compilation

共享描述编译：把流程描述构造为静态模型，装配文件节点库，展开引用与作用域，校验语言规则并解析语言引用。输出流程语义结果，流程实现从这一结果适配目标模型。

## 职责

- 描述构造：流程条目与节点库定义到静态模型，字段映射与缺省值。
- 节点类型：类型描述注册表、参数段读取与类型实例建立。
- 库装配：文件节点库校验、重名报错、引用展开与容器作用域。
- 校验：流程规则、节点规则与引用展开。
- 语义接入：调用流程语义完成作用域索引、输入来源与来源终点、静态来源链、容器端口映射、语言规则与诊断。
- 可解析性保证：引用存在、作用域唯一、静态来源链终止、容器映射完整、类型一致、可达性、常量依赖环与引用环成立。
- 规则分界：单节点不变量在定义共享层，跨节点语言规则与来源解析在流程语义，图视图约束由流程实现承担。

## 边界外

- 不含描述形态、静态模型与端口词汇的定义。
- 不含文件格式。
- 不含图视图装配、流程控制与运行期。
- 不含目标适配与目标可表达性判定。
