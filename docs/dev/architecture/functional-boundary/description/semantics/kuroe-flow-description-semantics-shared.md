# Kuroe.FlowDescription.Semantics.Shared

流程语言的语义契约与语义结果：承载节点定位、直接来源、来源终点、接线结果与解析诊断，供流程描述编译与流程实现适配使用。

## 职责

- 语义入口：接收展开后的流程定义，返回语言解析结果。
- 节点解析：按节点路径给出节点声明、输入记录与输出记录。
- 直接来源：动态输入与输出端口的来源节点与端口，开始端口与默认值没有节点来源。
- 来源终点：开始端口固定值、开始端口注入、节点端口产出、装配期常量、输入默认值、运行期常量与缺失的种类与载荷。
- 接线结果：动态输入与静态绑定的直接来源与来源终点，保留启动组与触发条件。
- 输出映射：输出端口的直接来源与取值终点。
- 诊断承载：节点定位与说明，由语义实现给出。

## 边界外

- 不含描述记录与文件格式。
- 不含静态模型、端口词汇与单节点规则。
- 不含构造、展开与语言规则实现。
- 不含图视图、目标流程模型与运行期。
- 不含目标可表达性判定与目标适配。
