# Kuroe.FlowDescription.Semantics

流程语言语义解释的实现：建立作用域索引，解析输入来源与静态来源链，映射容器输出端口，执行语言规则并给出诊断。只读解释展开后的流程定义，不构造目标模型。

## 职责

- 作用域索引：按容器层级建立标签到节点的解析。
- 输入来源解析：把动态输入与静态绑定的来源引用解析为直接来源与来源终点。
- 静态来源链：沿绑定链解析固定值、开始端口、默认值与运行期常量，识别缺失与环。
- 容器映射：把容器输出端口解析到子树成员的端口或本节点输入。
- 接线结果：按启动组给出动态绑定的来源、类型与触发条件，按绑定给出静态来源。
- 语言规则：类型一致、来源可见性、容器来源外部性、触发条件来源、组间来源端口重复、可达性、常量依赖环与引用环。
- 诊断：按节点定位给出来源缺失、作用域歧义、常量环、映射缺失与语言规则错误。

## 边界外

- 不含描述记录与静态模型。
- 不含描述构造与库展开。
- 不含图静态视图、接线绑定与流程控制。
- 不含 MAF 步骤、执行装配与运行期取值。
- 不含目标可表达性判定与目标适配。
