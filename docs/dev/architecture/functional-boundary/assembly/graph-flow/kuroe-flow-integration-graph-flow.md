# Kuroe.FlowIntegration.GraphFlow

图流程的宿主侧装配：在核心装配之后把图流程实现、节点类型、执行器、宿主开始输入与任务工作目录注册进容器，使核心任务运行时能提交并推进图流程任务。

## 职责

- 图流程装配入口：在核心装配之后注册流程库、节点类型描述、图节点能力、图流程提供者、流程模板与图记录编解码。
- 节点执行装配：把图节点类型绑定到节点项目给出的执行器，并注册输入与审批节点的输出投影。
- 模型声明解析：从图执行节点的静态模型端口取得模型名并校验可用性。
- 宿主开始输入：读取宿主开始输入表，把工作区、任务工作目录与当前模型解析为开始端口的值。
- 任务工作目录：按任务键建立与删除。
- 图流程扩展点：允许宿主追加节点类型描述与执行器注册。

## 边界外

- 不含核心装配与任务运行时。
- 不含图运行期、图控制与图共享层。
- 不含流程库、文件存取与导入。
- 不含节点类型与执行器实现。
- 不含 MAF 流程装配。
