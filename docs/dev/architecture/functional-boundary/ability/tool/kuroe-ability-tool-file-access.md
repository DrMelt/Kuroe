# Kuroe.Ability.Tool.FileAccess

文件访问实现：按行读取与游标、文本文件探测、截断与前缀处理，以及目录列表、行号渲染与搜索报告的文本输出。

## 职责

- 按行读取：保留每行原文终止符，按单行上限截断，识别 CRLF、CR 与 LF。
- 文本文件探测：读开头一段字节，按 BOM 与 NUL 判断文本格式。
- 文本截断：按 UTF-16 码元计数，不切开代理对，不留下单独的 CR。
- 文本输出：行号右对齐渲染、范围内省略标记、文件尾提示与带标记包裹。
- 目录列表文本：展示路径、条目名与目录标记，超限截断并提示。
- 搜索与替换报告文本：报告字符上限与命中窗口。

## 边界外

- 不含契约与结果形状。
- 不含工作区文件系统。
- 不含工具载体与模型侧输出。
