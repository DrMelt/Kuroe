# Kuroe.Host.Ability.Tool.Implementation.Git

git 工具组：状态查看、暂存与提交、分支与历史查看、合并与变基、补丁应用、清理与还原。全部是命令模板工具，命令在路径基准目录执行。

## 职责

- 工具源：装配期提供定义，运行期按执行绑定创建本轮可用的命令工具。
- 查看：工作树状态、改动、提交历史与单个提交。
- 暂存与提交：把改动放入暂存区、预演暂存、预演提交、预演删除，以及提交与删除已跟踪文件。
- 分支：列出分支、切换分支、合并修订与变基。
- 补丁与清理：应用补丁、清理未跟踪文件与目录、还原路径改动。

## 边界外

- 不含命令模板的执行与装配。
- 不含进程实现与仓库访问库。
- 不含工具文件配置。
