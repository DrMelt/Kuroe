# Kuroe.Ability.Runner.Llm

Llm 执行运行器：按一次执行建立会话与工具集合，发起模型请求，记录用量与过程内容，并产出可恢复的会话快照。

## 职责

- 执行参数：指令、能力路径、系统指令、工具变量映射与本次执行使用的模型。
- 运行器建立：为一次执行建立运行器，并校验与建立恢复执行。
- 会话：历史起点由执行的输入端口给出，执行期间来源不变，历史由会话快照与历史提供者承载。
- 模型调用观察：统计请求用量，把思考与回复写入过程记录。
- 工具集合：每次执行建立独立的工具载体，工具函数的参数形状与调用实参经宿主注册的工具载体对接。
- 产出契约补交：声明了输出端口却未交回时，给出写给模型的补交要求。
- 会话历史读取：从中性恢复数据读出消息，不接触模型客户端。
- 恢复数据：会话快照与所用模型的编解码与恢复判定。

## 边界外

- 不含节点类型与参数解析。
- 不含执行状态机与执行契约。
- 不含图、流程控制与任务域。
- 不含工具实现本身。
