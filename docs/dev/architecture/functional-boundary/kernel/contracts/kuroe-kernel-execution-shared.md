# Kuroe.Kernel.Execution.Shared

执行单元的中性形状与会话面：一次执行的身份、请求、过程记录、契约、产出、恢复数据与会话历史读取，同时声明运行器需要实现的接口。是中性的依赖叶子。

## 职责

- 执行身份：执行号、执行归属标识与执行步骤标识；归属与步骤由流程控制给出，本层只承载。
- 执行状态：排队、运行、收口与中断的取值。
- 执行请求：步骤标识、执行参数、输出端口声明与输入来源信息。
- 过程记录：执行期间的内容条目、进度文本与流式产出，供展示侧订阅，不进入存档。
- 执行契约：本轮已交回的端口产出、无法完成原因、本轮会话状态与端口校验规则。
- 执行产出与恢复数据：一次执行的可持久化结果。
- 会话历史读取：从恢复数据读出中性消息，不发起模型请求，不决定展示方式。
- 运行器接口：执行器工厂、执行器绑定、装配结果与恢复提供者，恢复由同一工厂提供。
- 错误与错误码：执行号不存在、端口名非法与契约非法。

## 边界外

- 不含状态机与派发。
- 不含任务与流程语义。
- 不依赖任何项目，不做序列化与展示格式。
