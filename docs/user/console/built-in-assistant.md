# 内置助手

## 会话

内置助手由多个会话组成。每个会话是一条独立的「对话」任务，有独立的历史、模型、回复语言、模式与标题。会话不出现在用户任务菜单中，不占用户任务号，保存在 `.kuroe_assistant/` 下。

会话页显示当前会话的历史与状态。会话列表用于新建与选择会话。跨会话可以并发执行；同一会话同一时刻只允许一轮，运行中再次发送被拒绝。

模型与回复语言在会话建立时固定。切换全局模型或 `Assistant:Language` 只影响新建会话；已有会话保持原配置。

模式按会话切换，下一轮生效，不重建任务，不清空历史。

## 历史

每轮对话是一次执行，输入、回复与状态保存在会话记录中。

会话页以用户与助手文本作为基础历史。其后的执行作为尾部显示，给出用户输入与执行状态。

展示层只显示用户与助手的文本。模型思考、工具调用与工具结果默认不显示。历史按消息分区块呈现，用户消息的标题是 `用户`，助手消息与尾部执行状态的标题是 `Kuroe 助手`。历史读取失败时给出错误，尾部仍按执行记录显示。历史消息过多时只显示最近一段并给出省略提示。

失败的轮次只显示输入与失败原因，可能保留部分助手文本。

## 后台轮次

发送消息后立即回到会话页，轮次在后台继续。离开会话页不阻断轮次，刷新会话页可以看到当前执行的输入与状态。会话页不显示实时输出，回复在下一轮重绘时从历史给出。轮次结束后由宿主在终端空闲时给出一行完成或失败提示；留在会话页期间提示在离开后显示，页内状态在下次重绘更新。

## 模式

助手有只读与更改两种模式，由用户在会话页切换，模型不能自行切换。模式决定下一轮可用的工具与系统指令，不重建会话，不清空历史。

| 模式 | 能力                                             |
| ---- | ------------------------------------------------ |
| 只读 | 读取工作区、查询状态与预演仓库操作               |
| 更改 | 只读能力加文件写入，不包含仓库改动与构建测试命令 |

## 工具白名单

助手按模式使用固定白名单：

- 只读：`KuroeInfo` 与 `source` 整组放行，另放行 `GetLocalTime`、`file/read`、`git/read` 与 `dotnet/read`。
- 更改：只读白名单加 `file/write`。

`git/read` 含暂存、提交与删除的只读预演函数，助手可以预演这三步，但不能改动仓库。更改模式不能提交、暂存或清理仓库，不能构建、测试、格式化项目，也不能调用 `.kuroe/tools.json` 声明的命令模板工具。助手工具以工作区根为路径基准。白名单说明见[工具配置](../reference/tool-configuration.md#工具白名单)，工具分组见[内置工具](../reference/tools/index.md)，工具的权限边界见[安全与权限](../usage/security-and-permissions.md)。
