# 交互操作

Kuroe.Console 的全部操作经菜单完成。启动后显示主菜单，方向键切换选项，回车进入选中项，Esc 返回上一级。输入表按 Esc 或提交空行取消并返回上一级。只读页进入后停在页内，选择「刷新」重印内容，按 Esc 或选择「返回上一级」退回上一层。Kuroe 助手是默认选中项，回车进入助手页，默认停在「发送消息」；发送消息的输入处按 Esc 或空行返回助手菜单，助手菜单按 Esc 返回主菜单。主菜单按 Esc 与选择「退出程序」相同，两者都要再次确认才结束进程。

每个菜单页顶部是一条面包屑横线，从「主菜单」开始逐级拼接，例如 `── 主菜单 › 任务 › 任务 #1 修复登录超时 ──`。页内内容与菜单各自占一个带标题的框。

入口差异见[入口与分工](../usage/入口与分工.md)，Kuroe.Cli 的命令见[命令行接口](../cli/命令行接口.md)。

`Ctrl+C` 由控制台默认处理，直接终止进程。

## 输入表

需要填写字段的操作先给出输入表；发送消息是连续对话输入，不使用输入表。上下文行只读，字段行按顺序填写；已填内容显示原文，凭据显示「已填写」，未填显示「未填写」，当前项目标「输入中」。每读取一项前重印整张表，全部填完后重印完整结果，再确认或保存。Esc 或空行取消整表，已填内容不保留。

## 主菜单

| 菜单项       | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| Kuroe 助手   | 助手页：发送消息、切换模型与重置对话                         |
| 任务         | 任务列表、提交任务、任务概览与执行详情                       |
| 流程         | 流程列表、节点树查看与文件导入                               |
| 工具         | 按路径树状打印全部可用工具                                   |
| 模型与提供商 | 目录总览、提供商与模型维护、目录导入导出                     |
| 设置         | 列出设置项并编辑用户层                                       |
| 退出程序     | 确认后取消全部任务并结束进程                                 |

## Kuroe 助手菜单

顶部打印当前模型与回复语言，选项为发送消息、切换模型、重置对话、返回主菜单。

- 发送消息进入连续输入循环，每行交给常驻对话任务；输入处按 Esc 或空行返回助手菜单
- 切换模型从已注册模型中选择，含取消选择；切换后下一轮对话起用新模型，历史按轮次保留
- 重置对话停止并丢弃当前对话任务，下一次输入重建

对话任务的工具白名单与专属工具见[内置助手与专属工具](内置助手与专属工具.md)。

## 任务菜单

顶部打印任务列表，选项为提交任务、选择任务、清理已完成与已取消、刷新、返回。提交任务先选流程，再用输入表按开始端口填写；不带固定值的端口是字段，带固定值的端口作为上下文，全部填完后确认提交。

选中任务后给出概览与执行清单，可选动作：

| 动作                 | 说明                                               |
| -------------------- | -------------------------------------------------- |
| 执行项               | 进入该执行的详情                                   |
| 批准待批准的节点     | 批准全部待批准节点，下游随之启动                   |
| 回答等待输入的节点   | 列出待输入节点与提问，选中节点后输入表给出节点与完整提问，填写回答 |
| 返工被阻塞的节点     | 重跑被阻塞的目标                                   |
| 改任务标题           | 输入表给出当前标题，只改标题，不重命名任务目录     |
| 查看节点树           | 进入节点树页，按流程树打印容器、执行节点与执行     |
| 查看过程记录         | 进入过程记录页，打印任务的过程记录                 |
| 取消整个任务         | 二次确认后取消，确认项默认停在保留任务             |
| 刷新                 | 重新读取任务状态                                   |
| 返回                 | 回任务列表                                         |

节点树页与过程记录页可刷新，返回上一层后重新打印任务页。

执行详情列出执行概要、输入取值与过程记录，可跳转到装配时引用的上游执行；未收口的执行可单独取消。

对话任务属于私有任务域，不出现在任务菜单，也不占用户任务号，由「Kuroe 助手」页的「重置对话」管理。

## 流程菜单

顶部打印流程列表，选项为查看流程详情、导入流程、刷新、返回。

- 查看流程详情先选流程，再进入流程详情页打印字段、开始端口、容器端口、执行节点的类型、模型、输入输出端口、工具、提问、执行上限与上游接线；页内可刷新，返回后回流程列表
- 导入流程用输入表填写文件路径，同名覆盖；文件须能独立装配

## 工具菜单

按路径打印全部可用工具的树，路径按 `/` 分段成层，同一前缀归入同一分支。叶行给出函数名、说明与参数，配置命令工具另给出模板。工具面覆盖内置工具、状态查询工具、契约工具与配置的命令工具；节点与对话的实际可用范围仍由各自白名单限定，见[工具扩展](../usage/工具扩展.md)与[内置助手与专属工具](内置助手与专属工具.md)。

没有可用工具时给出注册载体的检查提示。工具页可返回主菜单。

## 模型与提供商菜单

| 菜单项           | 说明                                                     |
| ---------------- | -------------------------------------------------------- |
| 查看目录         | 进入目录页，列出提供商与已注册模型，标记当前模型         |
| 添加提供商       | 用输入表填写提供商名称、端点与凭据，凭据只显示是否已填写 |
| 更换提供商凭据   | 选择提供商后用输入表填写新凭据，表内给出提供商           |
| 删除提供商       | 选择提供商并确认，仍被模型引用时拒绝                     |
| 注册模型         | 选择提供商后用输入表填写模型名，表内给出提供商           |
| 选择模型         | 从已注册模型中选择，含取消选择                           |
| 注销模型         | 选择模型并确认，注销当前模型时选择一并取消               |
| 导出目录         | 用输入表填写文件路径，凭据替换为占位符                   |
| 导入目录         | 用输入表填写文件路径，合并导入，冲突条目跳过并列出       |

导入后仍是占位符的凭据用「更换提供商凭据」替换。目录页可刷新，返回后回模型与提供商菜单。

## 设置菜单

顶部打印生效配置，逐项标记是否来自用户层；随后列出可编辑的设置项，每项标签为「节:项 · 当前值 · 来源」。

选中设置项后可写入新值或删除用户层设置。写入新值时输入表给出设置项与当前值。写入的值按 JSON 字面量解析，不是合法 JSON 时按字符串写入，写成 JSON null 时拒绝。模型选择不在设置菜单，由「模型与提供商」菜单维护。

各项含义见[设置与目录管理](../usage/设置与目录管理.md)。

## 输入规则

- 输入表按上述约定重印，Esc 或空行取消整表并返回上一级
- 凭据以掩码回显，输入表中只显示「已填写」
- 发送消息是连续对话输入，不使用输入表；输入处按 Esc 或空行返回助手菜单，其余输入原样交给助手，斜杠没有特殊含义；助手菜单按 Esc 返回主菜单
