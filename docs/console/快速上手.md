# 快速上手

从环境准备到完成第一个任务的最短路径。入口差异见[入口与分工](../usage/入口与分工.md)，产物与工作目录见[安装与运行](../usage/安装与运行.md)，从源码构建见[从源码构建](../usage/从源码构建.md)。

## 环境与依赖

Kuroe.Console 需要 .NET 10 运行时，以及可读键盘的交互终端——浏览任务与执行依赖键盘选择，输入被重定向时程序拒绝启动。从 release 页面下载编译产物压缩包并解压。脚本与 CI 中的一次性调用用 Kuroe.Cli，见[CLI 快速上手](../cli/快速上手.md)。

## 启动

在产物目录执行：

```powershell
dotnet Kuroe.Console.dll -d <工作目录>
```

`-d` 省略时用启动进程的当前目录。

## 注册模型

工作目录里还没有提供商与模型，先在主菜单进入「模型与提供商」，再注册并接通：

1. 选择「添加提供商」，用输入表填写名称、端点与凭据
2. 选择「注册模型」，选择提供商后用输入表填写模型名
3. 选择「选择模型」，选中刚注册的模型

提供商是模型的宿主，有名字、端点与凭据；模型注册到提供商名下。模型名是本地命名，与模型实际使用的名字无关，例如注册名 `gpt-4o` 指向提供商 `openai`。

未选择模型也能启动；对话或提交任务时才需要，未写或未注册时报错。

## 提交第一个任务

1. 主菜单进入「流程」查看流程名，需要时选择「导入流程」并用输入表填写文件路径
2. 回主菜单进入「任务」，选择「提交任务」，选流程后用输入表按开始端口填写并确认提交
3. 在任务列表选中任务，查看概览，可继续进入执行详情、节点树或过程记录

流程来自工作目录 `.kuroe/flows.json`。主菜单的「Kuroe 助手」进入常驻对话任务，随时可答，不需要任务在前台；对话任务不出现在任务菜单，见[交互操作](交互操作.md)。

## 输出形态

终端输出按用途分两种框：助手回合与详情列表用方角框，等待按键的选择与确认用圆角框。框标题写内容名，不加标记；启动横幅不带标题。每个菜单页以 `──` 横线标题划出层级，横线与标题用强调色，标题加粗，标题写成从主菜单开始的面包屑路径，例如 `── 主菜单 › 任务 ──`。单行提示、错误与流式文本不进框。
