# 内置助手

## 对话任务

「Kuroe 助手」页的普通输入进入常驻对话任务。它是「对话」流程的常驻任务，随时可答，不需要任务在前台，注册模型后可以自然语言询问任务、执行、流程、模型目录、配置与工具名单；没有模型时返回固定引导。对话任务不出现在任务菜单中，也不占用户任务号。重置对话重建任务，回到起点。

助手使用当前选中的模型，同一对话任务内历史按轮次保留。切换模型后下一轮重建任务，上下文清空。`Assistant:Language` 控制回复语言，已有对话任务需「重置对话」后生效，见[设置](../usage/设置.md)。

## 内置助手工具白名单

助手使用固定白名单：`KuroeInfo` 与 `source` 整组放行，另放行 `GetLocalTime`、只读的 `file/read`、`git/read` 与 `dotnet/read`。`git/read` 含暂存、提交与删除的只读预演函数，助手可以预演这三步，但不能改动仓库。助手工具以工作区根为路径基准。白名单说明见[工具配置](../reference/工具配置.md#工具白名单)，工具分组见[内置工具](../reference/tools/index.md)，工具的权限边界见[安全与权限](../usage/安全与权限.md)。
