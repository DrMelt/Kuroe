# 内置助手

## 对话任务

「Kuroe 助手」页的普通输入进入常驻对话任务。它是「对话」流程的常驻任务，随时可答，不需要任务在前台，注册模型后可以自然语言询问任务、执行、流程、模型目录、配置与工具名单；没有模型时返回固定引导。对话任务不出现在任务菜单中，也不占用户任务号。重置对话重建任务，回到起点。

助手使用当前选中的模型，同一对话任务内历史按轮次保留。每轮以上一轮执行的 Llm 会话快照为历史起点，用户输入、回复与工具调用结果留在历史中。切换模型后下一轮重建任务，上下文清空。`Assistant:Language` 控制回复语言，已有对话任务需「重置对话」后生效，见[设置](../usage/设置.md)。

## 模式

助手有只读与更改两种模式，由用户在助手页切换，模型不能自行切换。模式决定下一轮可用的工具与系统指令，不重建对话任务，不清空历史。

| 模式 | 能力                                             |
| ---- | ------------------------------------------------ |
| 只读 | 读取工作区、查询状态与预演仓库操作               |
| 更改 | 只读能力加文件写入，不包含仓库改动与构建测试命令 |

模式切换在下一轮生效。重置对话保留当前模式。切换模型重建任务并清空上下文，模式保留。模式是 Console 运行期选择，重启后回到只读。

## 工具白名单

助手按模式使用固定白名单：

- 只读：`KuroeInfo` 与 `source` 整组放行，另放行 `GetLocalTime`、`file/read`、`git/read` 与 `dotnet/read`。
- 更改：只读白名单加 `file/write`。

`git/read` 含暂存、提交与删除的只读预演函数，助手可以预演这三步，但不能改动仓库。更改模式不能提交、暂存或清理仓库，不能构建、测试、格式化项目，也不能调用 `.kuroe/tools.json` 声明的命令模板工具。助手工具以工作区根为路径基准。白名单说明见[工具配置](../reference/工具配置.md#工具白名单)，工具分组见[内置工具](../reference/tools/index.md)，工具的权限边界见[安全与权限](../usage/安全与权限.md)。
