# 内置助手

## 对话任务

普通输入与常驻对话任务对话。对话任务是「对话」流程的常驻任务，随时可答，不需要任务在前台：注册模型后它可以自然语言回答任务、执行、流程、模型目录、配置与工具名单的询问，由内置状态查询工具取回；没有模型时返回固定引导。对话任务属于内置助手的内部任务，不出现在任务菜单与 `KuroeInfo` 的任务查询，也不占用户任务号；「Kuroe 助手」页的「重置对话」停止并重建对话任务，回到起点。任务菜单见[操作指南](操作指南.md)。

助手使用当前选中的模型。同一对话任务内历史按轮次保留；切换模型后下一轮重建任务并使用新模型，上下文随重建清空。`Assistant:Language` 控制回复语言，作为系统指令的一部分；已有对话任务需在「Kuroe 助手」页选择「重置对话」后生效，见[设置](../usage/设置.md)。

## 内置助手工具白名单

助手使用固定白名单，未列入的工具不可用。白名单写 `KuroeInfo`、`source` 即整组放行，另放行 `GetLocalTime`、只读的 `file/read`、只读的 `git/read` 与只读的 `dotnet/read`，git 与 dotnet 的写操作不在白名单里。助手工具以工作区根为路径基准。文件工具拒绝 `.kuroe` 与 `.git` 路径，符号链接、目录联接点与硬链接不解析。工具白名单说明见[工具配置](../reference/工具配置.md)与[内置工具](../reference/内置工具.md)。
