# 操作指南

Kuroe.Console 是交互终端，覆盖内置助手、任务、流程、工具、模型与提供商、设置的浏览与维护，全部页面由主菜单逐级进入。启动方式与工作目录见[快速开始](../快速开始.md)，环境要求与产物目录见[安装与运行](../usage/安装与运行.md)。

## 交互约定

- 菜单用键盘操作：方向键切换菜单项，Enter 进入选中项，Esc 返回上一级；选项多于一页时 PageUp、PageDown 翻页，Home、End 到首尾。
- 输入表逐项填写：未填的必填项排在前面，必填项填完后出现提交项，可留空的项不影响提交；选择提交返回全部输入，选择取消放弃整个输入表。填写任一项时取消该字段输入即放弃整个输入表。
- 需要再确认的动作默认停在保留现状的选项，只有选中确认项才执行。
- 单行输入回车提交，空行或 Esc 取消。
- 多行输入回车换行，单独一行 `;;` 提交，终止行不计入内容；行首退格把当前行并入上一行；Esc 或空内容取消。值中不能包含单独一行的 `;;`。
- 凭据按掩码回显，始终单行。

状态与提示用颜色区分：绿色表示成功或已完成，蓝色表示键名与执行中，黄色表示警告、阻塞或等待，红色表示错误或失败，灰色表示提示与次要信息。

## 页面与屏幕

页面与终端屏幕一一对应。每次写页面标题都会重绘屏幕：启动后的首个页面保留启动横幅，其后先清理可见屏幕与滚动区历史，光标回到左上角，页面标题从首行开始。

- 每轮回到本页都清屏重绘：刷新、执行动作、选择菜单项、取消输入表与确认操作后，页面从首行重新呈现。
- 动作结果、错误提示与页内输出在下一轮重绘时消失，需要保留的信息由对应页面重绘时重新给出。
- 助手页在进入时清屏一次，页内的对话、工具输出与菜单继续累加，对话记录保留到离开助手页。
- 页内弹层与页面标题走不同通道，菜单、输入表、确认框与行输入不触发清理。
- 输出不支持控制序列时不写清理序列，页面按追加方式呈现，滚动区历史保留。

支持控制序列时，上一页的可见内容与滚动区历史在进入新页面或刷新后都不再存在。启动横幅只出现在首屏，回到主菜单不再显示。后台通知的排队与冲刷时机不随页面变化。

## 主菜单

启动后进入主菜单，固定七个入口：

| 入口         | 去向                                    |
| ------------ | --------------------------------------- |
| Kuroe 助手   | 常驻对话任务，见[内置助手](内置助手.md) |
| 任务         | 任务列表与逐级下钻                      |
| 流程         | 流程列表、详情与导入                    |
| 工具         | 只读工具树                              |
| 模型与提供商 | 目录与模型、提供商维护                  |
| 设置         | 生效配置的查看与写入                    |
| 退出程序     | 保存未完成任务并退出                    |

选择「退出程序」后要求再次确认，默认停在返回主菜单的选项，确认后保存未完成任务并退出。

## Kuroe 助手

助手页顶部显示当前模型与回复语言，菜单四项：

| 菜单项     | 作用                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 发送消息   | 进入连续输入，逐条发送给常驻对话任务，空行或 Esc 回到助手菜单          |
| 切换模型   | 进入模型选择，与「模型与提供商」菜单的「选择模型」同一入口，可取消选择 |
| 重置对话   | 停止并重建常驻对话任务，回到起点                                       |
| 返回主菜单 | 回到主菜单                                                             |

对话任务的职责、模型与回复语言如何生效见[内置助手](内置助手.md)。

## 任务

任务页按列表、概览、执行详情三级下钻，另有节点树与过程记录两个只读页。

### 任务列表

列表一行一个任务，给出任务键的末尾 8 位、标题、流程、创建时间、状态、待处理数与最近活动。任务概览给出完整任务键。菜单项：

| 菜单项                   | 作用                                                                                                                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 刷新                     | 重新读取任务列表                                                                                                                                                                                                     |
| 选择一个任务             | 进入该任务的概览                                                                                                                                                                                                     |
| 提交任务                 | 先选流程，再按开始端口填写输入，最后确认提交。承载内容、不带固定值且不在宿主开始输入表里的开始端口逐项填写，常量内容端口也包含在内；带 `Default` 的端口预填默认值，仍可修改；不承载内容的开始端口、带固定值与在宿主开始输入表里的端口作为只读行展示 |
| 清理已完成与已终止的任务 | 丢掉内存中的已完成或已终止任务并删除其存档                                                                                                                                                                           |
| 退出浏览                 | 回到主菜单                                                                                                                                                                                                           |

开始输入与回答等待输入使用多行输入。

流程写法见[流程定义](../reference/流程定义.md)。

任务存档见[安装与运行](../usage/安装与运行.md#任务存档)。

### 任务概览

概览给出任务输入、流程、状态、创建时间与最近活动，下方是待处理节点表、阻塞节点表与执行清单，执行号是进入执行详情的入口。菜单项：

| 菜单项                     | 作用                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| 刷新                       | 重新读取任务概览                                                 |
| 选择一个执行               | 进入该执行的执行详情                                             |
| 批准待批准的节点，开下一步 | 存在待批准节点时出现，批准全部待批准节点并继续                   |
| 回答等待输入的节点         | 存在待输入节点时出现，多节点时先点名再回答，空回答不构成输入     |
| 重新执行被阻塞的节点       | 存在阻塞节点时出现，放弃恢复并新建一次执行，不继承上次执行历史，已保存的恢复数据保留 |
| 暂停任务                   | 停止派发新执行并中断在跑执行，任务可恢复                         |
| 恢复任务                   | 任务暂停或存在恢复计划时出现，派发恢复计划并恢复推进             |
| 终止整个任务               | 不可恢复，选择后要求再次确认                                     |
| 改任务标题                 | 改写任务标题                                                     |
| 查看节点树                 | 打开节点树只读页                                                 |
| 查看过程记录               | 打开过程记录只读页                                               |
| 返回                       | 回到任务列表                                                     |

可恢复的中断收口后任务自动暂停，只停止新的调度，不中断在跑的执行。恢复任务会派发恢复计划并从上次中断处继续，恢复执行继承来源执行已交回的端口与无法完成原因，已交回端口无需再次提交。重新执行则让当前阻塞不再可恢复、作废目标节点已发布产出，并按当前输入新建一次执行，不继承上次执行的会话历史；已保存的恢复数据保留。已上报无法完成的执行是否可恢复由节点类型判断，Llm 不提供恢复。网络中断、超时、停止执行、暂停任务与进程退出使用同一套恢复语义，都通过恢复任务继续。可恢复的节点在阻塞表与节点树里标记为可恢复。

### 执行详情

执行详情给出概要、输入取值及其出处、过程记录。概要含任务、节点、轮次、请求次数、模型、token 用量、上下文、状态、恢复数据、继续来源、起止与耗时。请求次数后附未返回用量的次数。token 用量分输入、输出与合计三项，缓存输入写在输入项内，推理写在输出项内；输入与输出给出占合计的比例，缓存输入给出占输入的比例，推理给出占输出的比例；基数未知、为 0 或子项大于母类时不显示比例。上下文取最近一次返回用量的请求的输入 token 数，不随请求累计；该请求没有给出输入 token 数，或其后有请求未返回用量时显示未提供。provider 未返回用量时用量显示未提供。请求次数与用量在执行运行中为当前累计，收口后为最终值。菜单项：

| 菜单项       | 作用                                                         |
| ------------ | ------------------------------------------------------------ |
| 刷新         | 重新读取执行详情                                             |
| 上游执行跳转 | 输入取值来自其他执行时列出其出处，选择即跳转到该执行         |
| 停止该执行   | 执行已启动且尚未结束时出现，停止这个执行，Llm 节点可在恢复任务后继续 |
| 返回         | 回到任务概览                                                 |

### 只读页

- 节点树按流程树列出容器、执行节点与执行，执行作为执行节点的子行，容器行给出成员完成进度，阻塞节点行给出阻塞原因与可恢复标记。
- 任务过程记录是任务级权威记录，呈现最近 40 条记录，更早的只报条数。执行过程记录只在运行中可见，重启后执行详情不再显示；执行恢复数据随执行记录保留，重启后仍可查看。

状态展示名：

- 任务：执行中、已阻塞、已暂停、已完成、已终止
- 执行节点：待执行、执行中、已阻塞、已完成、已取消
- 单次执行：排队中、执行中、已完成、失败、已中断

未收口的执行在状态后附当前活动：工具调用期间显示 `调用工具 <工具路径>`，思考与输出期间显示 `思考` 与 `输出`。

## 流程

流程页列出流程库及规模，菜单项：

| 菜单项       | 作用                                         |
| ------------ | -------------------------------------------- |
| 刷新         | 重新读取流程库                               |
| 查看流程详情 | 打印流程字段与节点树，含执行节点、容器与说明 |
| 导入流程     | 按文件路径导入节点库或流程，可用的同名项覆盖 |
| 返回         | 回到主菜单                                   |

流程的写法与节点库见[流程定义](../reference/流程定义.md)。

## 工具

工具页显示全部可用工具的只读树，按路径分段成层，叶行给出函数名、说明、参数与配置形态。没有可用工具时给出来源提示。工具白名单与内置工具见[工具配置](../reference/工具配置.md)与[内置工具](../reference/tools/index.md)。

## 模型与提供商

菜单页顶部显示当前模型，菜单项：

| 菜单项         | 作用                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 查看目录       | 列出提供商与模型，标记当前模型                                                 |
| 添加提供商     | 输入表填写提供商名称、端点与凭据，凭据按掩码回显                               |
| 更换提供商凭据 | 选择提供商后输入新凭据                                                         |
| 删除提供商     | 选择提供商后确认，仍被模型引用时由目录拒绝                                     |
| 注册模型       | 选择提供商后填写本地模型名与提供商模型名，后者留空时用前者                     |
| 选择模型       | 选择已注册的模型或取消选择                                                     |
| 注销模型       | 选择模型后确认，注销的是当前模型时选择一并取消                                 |
| 导出目录       | 输入文件路径，导出时凭据替换为占位符                                           |
| 导入目录       | 输入文件路径，合并导入，已有条目不受影响，占位符凭据需用「更换提供商凭据」替换 |

提供商与模型的含义、选择与迁移见[模型接入](../usage/模型接入.md)。

## 设置

设置页顶部显示用户层文件路径，按节列出生效配置，逐项标记是否已写入用户层。菜单项：

| 菜单项         | 作用                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| 刷新           | 重新读取生效配置                                                                                     |
| 选择一个设置项 | 进入编辑，可写入新值或删除已有用户层设置。写入的新值按 JSON 字面量解析，不是合法 JSON 时按字符串写入 |
| 返回           | 回到主菜单                                                                                           |

模型选择由「模型与提供商」菜单维护，不进入设置编辑列表。设置项含义与来源见[设置](../usage/设置.md)。
