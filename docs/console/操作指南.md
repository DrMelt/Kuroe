# 操作指南

Kuroe.Console 是交互终端，覆盖内置助手、任务、流程、工具、模型与提供商、设置的浏览与维护，全部页面由主菜单逐级进入。Console 要求可读键盘的交互终端，输入或输出被重定向时拒绝启动。启动方式与工作目录见[快速开始](../快速开始.md)，环境要求与产物结构见[安装与运行](../usage/安装与运行.md)。

## 交互约定

- 菜单用键盘操作：方向键切换菜单项，Enter 进入选中项，Esc 返回上一级；选项多于一页时 PageUp、PageDown 翻页，Home、End 到首尾。
- 输入表逐项填写：未填的项排在前面，全部填完后出现提交项，选择提交返回全部输入，选择取消放弃整个输入表。填写任一项时空行或 Esc 同样放弃整个输入表。
- 需要再确认的动作默认停在保留现状的选项，只有选中确认项才执行。
- 行输入回车提交，Esc 或空行取消；凭据按掩码回显。

状态与提示用颜色区分：绿色表示成功或已完成，蓝色表示键名与执行中，黄色表示警告、阻塞或等待，红色表示错误或失败，灰色表示提示与次要信息。

## 主菜单

启动后进入主菜单，固定七个入口：

| 入口         | 去向                                    |
| ------------ | --------------------------------------- |
| Kuroe 助手   | 常驻对话任务，见[内置助手](内置助手.md) |
| 任务         | 任务列表与逐级下钻                      |
| 流程         | 流程列表、详情与导入                    |
| 工具         | 只读工具树                              |
| 模型与提供商 | 目录与模型、提供商维护                  |
| 设置         | 生效配置的查看与写入                    |
| 退出程序     | 取消全部任务并退出                      |

选择「退出程序」后要求再次确认，默认停在返回主菜单的选项，确认后取消全部任务并退出。

## Kuroe 助手

助手页顶部显示当前模型与回复语言，菜单四项：

| 菜单项     | 作用                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 发送消息   | 进入连续输入，逐条发送给常驻对话任务，空行或 Esc 回到助手菜单          |
| 切换模型   | 进入模型选择，与「模型与提供商」菜单的「选择模型」同一入口，可取消选择 |
| 重置对话   | 停止并重建常驻对话任务，回到起点                                       |
| 返回主菜单 | 回到主菜单                                                             |

对话任务的职责、模型与回复语言如何生效见[内置助手](内置助手.md)。

## 任务

任务页按列表、概览、执行详情三级下钻，另有节点树与过程记录两个只读页。

### 任务列表

列表一行一个任务，给出任务号、标题、流程、创建时间、状态、待处理数与最近活动。菜单项：

| 菜单项                   | 作用                                                                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 选择一个任务             | 进入该任务的概览                                                                                                                              |
| 提交任务                 | 先选流程，再按开始端口填写输入，最后确认提交。不带固定值且未绑定 `HostStartInputs` 的开始端口逐项填写，带固定值与宿主绑定的端口作为只读行展示 |
| 清理已完成与已取消的任务 | 丢掉内存中的已完成或已取消任务                                                                                                                |
| 刷新                     | 重新读取任务列表                                                                                                                              |
| 退出浏览                 | 回到主菜单                                                                                                                                    |

提交任务的完整流程见[快速开始](../快速开始.md)，流程写法见[流程定义](../reference/流程定义.md)。

### 任务概览

概览给出任务输入、流程、状态、创建时间与最近活动，下方是待处理节点表与执行清单，执行号是进入执行详情的入口。菜单项：

| 菜单项                     | 作用                                                         |
| -------------------------- | ------------------------------------------------------------ |
| 选择一个执行               | 进入该执行的执行详情                                         |
| 批准待批准的节点，开下一步 | 存在待批准节点时出现，批准全部待批准节点并继续               |
| 回答等待输入的节点         | 存在待输入节点时出现，多节点时先点名再回答，空回答不构成输入 |
| 返工被阻塞的节点           | 存在阻塞节点时出现，返工被阻塞的节点                         |
| 取消整个任务               | 不可恢复，选择后要求再次确认                                 |
| 改任务标题                 | 改写任务标题                                                 |
| 查看节点树                 | 打开节点树只读页                                             |
| 查看过程记录               | 打开过程记录只读页                                           |
| 刷新                       | 重新读取任务概览                                             |
| 返回                       | 回到任务列表                                                 |

### 执行详情

执行详情给出概要、输入取值及其出处、过程记录。概要含任务、节点、轮次、模型、状态、起止与耗时。菜单项：

| 菜单项       | 作用                                                 |
| ------------ | ---------------------------------------------------- |
| 上游执行跳转 | 输入取值来自其他执行时列出其出处，选择即跳转到该执行 |
| 取消该执行   | 执行未收口时出现，取消这个执行                       |
| 刷新         | 重新读取执行详情                                     |
| 返回         | 回到任务概览                                         |

### 只读页

- 节点树按流程树列出容器、执行节点与执行，执行作为执行节点的子行，容器行给出成员完成进度。
- 过程记录呈现最近 40 条记录，更早的只报条数。

任务的状态展示名：执行中、已阻塞、已完成、已取消。执行节点的状态展示名：待执行、执行中、已阻塞、已完成、已取消。单次执行的状态展示名：排队中、执行中、已完成、失败、已取消。

## 流程

流程页列出流程库及规模，菜单项：

| 菜单项       | 作用                                             |
| ------------ | ------------------------------------------------ |
| 查看流程详情 | 打印流程字段与节点树，含执行节点、容器与说明     |
| 导入流程     | 按文件路径导入流程与节点库，可编译的同名流程覆盖 |
| 刷新         | 重新读取流程库                                   |
| 返回         | 回到主菜单                                       |

流程的写法与节点库见[流程定义](../reference/流程定义.md)。

## 工具

工具页显示全部可用工具的只读树，按路径分段成层，叶行给出函数名、说明、参数与配置形态。没有可用工具时给出来源提示。工具面与内置工具见[工具配置](../reference/工具配置.md)与[内置工具](../reference/内置工具.md)。

## 模型与提供商

菜单页顶部显示当前模型，菜单项：

| 菜单项         | 作用                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 查看目录       | 列出提供商与模型，标记当前模型                                                 |
| 添加提供商     | 输入表填写提供商名称、端点与凭据，凭据按掩码回显                               |
| 更换提供商凭据 | 选择提供商后输入新凭据                                                         |
| 删除提供商     | 选择提供商后确认，仍被模型引用时由目录拒绝                                     |
| 注册模型       | 选择提供商后填写模型名                                                         |
| 选择模型       | 选择已注册的模型或取消选择                                                     |
| 注销模型       | 选择模型后确认，注销的是当前模型时选择一并取消                                 |
| 导出目录       | 输入文件路径，导出时凭据替换为占位符                                           |
| 导入目录       | 输入文件路径，合并导入，已有条目不受影响，占位符凭据需用「更换提供商凭据」替换 |

提供商与模型的含义、选择与迁移见[模型接入](../usage/模型接入.md)。

## 设置

设置页顶部显示用户层文件路径，按节列出生效配置，逐项标记是否已写入用户层。菜单项：

| 菜单项         | 作用                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| 选择一个设置项 | 进入编辑，可写入新值或删除已有用户层设置。写入的新值按 JSON 字面量解析，不是合法 JSON 时按字符串写入 |
| 刷新           | 重新读取生效配置                                                                                     |
| 返回           | 回到主菜单                                                                                           |

模型选择由「模型与提供商」菜单维护，不进入设置编辑列表。设置项含义与来源见[设置](../usage/设置.md)。
