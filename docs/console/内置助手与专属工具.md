# 内置助手与专属工具

## 对话任务

普通输入与常驻对话任务对话。对话任务是「对话」流程的常驻任务，随时可答，不需要任务在前台：注册模型后它可以自然语言回答任务、执行、流程、模型目录、配置与工具名单的询问，由内置状态查询工具取回；没有模型时返回固定引导。对话任务属于内置助手的私有任务域，不出现在任务菜单与 `KuroeInfo` 的任务查询，也不占用户任务号；「Kuroe 助手」页的「重置对话」停止并重建对话任务，回到起点。任务菜单见[交互操作](交互操作.md)。

回话节点使用 `Runtime:Model` 当前选中的模型。切换模型后对话下一轮起用新模型，历史按轮次保留。`Assistant:Language` 控制回复语言，作为系统指令的一部分；已有对话任务需在「Kuroe 助手」页选择「重置对话」后生效，见[设置与目录管理](../usage/设置与目录管理.md)。

## 固定工具白名单

回话节点用固定白名单，未列入的工具不可用。白名单写 `KuroeInfo`、`source` 即整组放行，另放行 `GetLocalTime`、只读的 `git/read` 与只读的 `dotnet/read`，git 与 dotnet 的写操作不在白名单里。对话任务没有工作目录，`file` 不在白名单里。共用工具面见[工具扩展](../usage/工具扩展.md)。

助手工具由 `AssistantServiceCollectionExtensions.AddKuroeAssistant` 并入核心工具集，去重校验跨核心与助手两次并入。

## 导出资料工具

产物目录的 `source/` 下是构建时的仓库源码与文档，保留仓库相对路径；目录由 Kuroe.Console 以产物位置装配成只读的 `source` 工具组，用于查阅程序自身的实现，不随工作目录变化。

| 函数                         | 作用                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------ |
| `source/ListSourceDirectory` | 列出导出目录内一个目录的直接子项，`path` 缺省为导出目录根                                  |
| `source/ReadSourceFile`      | 读取导出目录内文件指定行号范围，`from`/`to` 是行号，缺省读前 50 行，超出文件行数读到文件尾 |

路径相对导出目录，路径参数在调用前统一校验，解析后必须落回导出目录内，越界或空值被拒绝，根目录通过省略 `path` 表达；条目只读，没有写入函数。读取内容与文件访问工具一样按 8000 字符截断。导出的源码与文档不对模型隐藏，产物分发即源码分发。该工具组只随 Kuroe.Console 装配。

## 状态查询工具

`KuroeInfo/ListTools` 报内置对话放行的路径前缀与配置命令工具的调用名和路径，只随 Kuroe.Console 装配。其余 `KuroeInfo` 函数由两个入口共用，见[工具扩展](../usage/工具扩展.md)。
