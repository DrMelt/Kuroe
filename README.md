# Kuroe

Kuroe 把用户定义的「流程」交给模型执行。流程是节点组成的任务模板，节点声明模型、输入输出与可调用的工具；模型按流程接线推进，产出交给下游，或用工具读写文件、执行命令完成任务。

有两个人入口，共用同一份工作目录配置：

| 入口 | 用途 |
| --- | --- |
| Kuroe.Console | 交互终端，可浏览任务、等待输入与批准，带内置助手 |
| Kuroe.Cli | 脚本与 CI 中的一次性命令，进程退出即结束 |

## 快速开始

目标机需要 .NET 10 运行时。从 release 下载编译产物解压后，在产物目录执行：

```powershell
dotnet Kuroe.Console.dll -d <工作目录>
```

完整上手见 [快速开始](docs/快速开始.md)，使用说明见 [docs](docs/README.md)。
